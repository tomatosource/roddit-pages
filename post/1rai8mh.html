TIL Charlie Berry is the only player to be teammates with both Carl Sumner (the only player ever with the surname Sumner) and Les Tietje (the only player ever to be from Sumner, Iowa).

Carl Sumner’s only MLB action was 16 games for the 1928 Red Sox.

Les Tietje debuted with the 1933 White Sox.

Charlie Berry played for both teams and alongside both players. And he was the only one to have done so.
