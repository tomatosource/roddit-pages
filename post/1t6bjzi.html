I built a free interactive PoE 2 levelling guide + resource hub — poe2.info

Hey exiles,

I’ve been working on poe2.info — a free, browser-based tool for campaign progression. No login, no ads, no install.

The levelling guide covers Acts 1–4 + Interludes (Patch 0.4):

  • Every permanent reward flagged — skill points, spirit, resistances, ascendancy
  • ⚡ Fast Run mode tracks only the must-do steps, ✦ Complete tracks everything
  • Click any reward in the summary box to jump and highlight it in the guide
  • Progress saves to your browser automatically and exports/imports via a shareable code
  • Collapse individual zones or mark an entire zone done in one click

There’s also a resources panel (grinding.zone) with curated links for filters, build tools, crafting simulators, economy trackers, overlays and more — all PoE 2 specific.

Big credit to Domistae on GitHub whose open source levelling guide was the original inspiration and foundation I built on top of. Wouldn’t exist without it.

Still actively updating — if anything is wrong or missing let me know. Happy to update it.

https://poe2.info/
