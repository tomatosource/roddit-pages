GGG Make a Performance Benchmark and collect all the data you can, we’re here to help.

We all know that PoE2 is having performance issues on a variety of hardware. I can run just about any game on my PC, including PoE1 with very little issue, yet PoE2 suffers from sudden lockups, CPU spikes, missing textures, etc.

We as a community joined the early access. We want to help. Make a standard performance benchmark we can all run that submits diagnostics back to your team.

How many people run with the optional debug/report flag on startup? Just make a standalone binary to do this testing that we can launch from the game menu, and make it mirror end game map density.

Maybe in the future, this benchmark could then help a novice user dial in the settings best used on their PC or Console for optimal performance.
