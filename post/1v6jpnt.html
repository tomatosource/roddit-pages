Cast on block power charges tech

Hi! New to the sub, really enjoy the game. Found a cool tech using cast on block from the Svalinn unique shield the other day and wanted to share. It also uses some of the new Kalguuran skills to generate power charges.

I’m running totems without the spirit cost node so I need power charges. To get the charges I use Runic Reprieve (since my stun threshold is bad and it looks cool) and cast on block, in which I have slotted Powered by Verisium and Firestorm.
