Found a pretty neat setup ~ LHand Gamepad RHand Mouse

The gamepad AI is pretty neat, but certain ground-target abilities like Frost Bomb are not really setup for ground targeting with a gamepad. It’s either max range or on-top of you, unless I’m missing something.

If for some reason (your target just died) you lose target, then it can snap to max range in the movement direction instead, often not where you wanted..

Anyway, I found a way to play that I think you might find superior to KB & gamepad. That is, except for when typing in chat or a filter.

Joystick = WASD bindings with Space on click

LT = Shift

LB = CTRL

Then, in-game bindings:

Health/Mana = MB4 / MB5

Normal abilities LMB, MMB, RMB

First actionbar

Shift + ( MB4 / MB5 / LMB / MMB / RMB )

Second actionbar

CTRL + ( MB4 / MB5 / LMB / MMB / RMB )

Above are all the gameplay bindings, but you can add menus to the DPAD or the select button.

That’s it! I just thought some people might find this really a good idea! Cheers
