Console fix for Crossbow not shooting when different Crossbows are equipped

In your inventory go to Skills, press your Set Skill Bind button (square on PS, X on Xbox) and you will see two rows of skill bind slots. Unfortunately, we have to use one for Set 1 Crossbow and the other for Set 2 Crossbow. For example:

https://preview.redd.it/q5lw5iepx9hg1.jpg?width=1753&format=pjpg&auto=webp&s=3057747412bbb33586a4eaecdb26dbf53a1ae0a5

As you can see, I have most of my crossbow skills in the top row, those are all used in Set 1 Crossbow and they are alloted to Set 1. Fragmentation Rounds is at the bottom, that one is used with Set 2 Crossbow and is alloted to Set 2.

It’s important to note a couple things.

  1. To use the bottom row skills it’s required to hold the L2 button (or Left Trigger on Xbox). For that reason, I’d advise against making the bottom row your main row because then you’d have to constantly hold the button which may damage the button, your finger and your patience. Fragmentation Rounds for me is at the bottom row because it’s only used for burst damage against tough enemies for short period of time.
  2. Switching to a bottom row skill does not require a reload since you’re actually switching crossbows and not reloading the same one.
  3. Finally, pay close attention to the guide you’re following. They may have a specific crossbow in a specific set and then they’d have passive points for that set. Make sure you’re using the correct passive points with the correct crossbow. In my case, the guide had Rampart Raptor in Set 1 which is the red skills in the tree but I have it in Set 2, so my red skill tree is inverted.
  4. If your guide states that the same Crossbow is used in both Sets, then none of this is necessary.

I suspect the reason this happens is because unlike spells, Crossbow shots need to be loaded in. Pressing the skill does not fire, instead we have a dedicated fire button. When I was trying to play normally, it would only sometimes randomly switch skills. Unfortunately, we also have less buttons on controller.

This all may be common knowledge, but I was still struggling yesterday to make it work so someone out there could still need the info.
