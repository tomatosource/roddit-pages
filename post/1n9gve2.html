Tests: Lightning Arrow interactions with Fork and Pierce

I didn’t find information on Beam interactions between LA and and Fork/Pierce, so i conducted my own tests, recorded them and compared frame by frame.

Lightning Arrow supported by Fork creates 3 new LA projectiles after Hitting the target and Beams from the Hit. All of newly created LA arrows are also capable of creating Beams on Hit.

Lightning Arrow supported With “Arrows Pierce an additional target” creates Beams after hitting first target and retain the same projectile. Same projectile still capable to create new Beams on Hit. In other worlds, there is no limits on how many times LA can create “Beams on Hit”.

Proofs:

Beams from first Hit (they are attached to projectile, not enemy)

Beams from second Hit

Conclusions: Forks provides wider coverage because of secondary projectiles flying sideways, Pierce allows Bows to achive higher DPS because it can be obtained throuth Passive tree, freeing Support Gem slot and doesn’t have damage reduction for consequent hits.

TLDR: Same LA projectile can trigger Beams multiple times if it Hits more than once.
