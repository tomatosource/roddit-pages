Path of Exile 2 couch co-op on PS5

The GF and I started playing POE2 during the free weekend on PS5, enjoyed it a lot, and decided to buy the EA. The only thing bothering us so far is how loot sharing works in couch co-op.

Even when we change the loot allocation to permanent, it still basically feels like “first one to pick it up gets it.” Trading items between each other is easy enough, so it’s not a huge issue, but it still feels a bit off in a game that’s all about getting upgrades from loot drops.

What’s more frustrating is that sometimes zone rewards only drop for one player instead of both. The Valley of the Titans unique reward, for example, only dropped for one of us.

We’re still having an amazing time with POE2, but I wanted to ask if there has been any communication regarding couch co-op improvements or plans for upcoming patches?
