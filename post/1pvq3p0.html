Loot from 200x Xeshts

Just wanted to boss farm something in POE2. Also, there’s not much data regarding loot (sample size = 143), so I decided to check existing data and fish for some juicy gems.

I’ve run 200 Xeshts, buying and running them in batches of 20 runs, collecting results, selling some stuff, and redoing this 10 times. All screenshots with all loot you can find in Excel doc down below.

Time invested - around 3 days. Usually, it takes 3 min for a run, but I tried to record everything, sorting loot etc. So it was more of a 5-6 min for a run.

Catalysts:
I wouldn’t be sane if I counted every single catalyst during these runs. I just checked how many exalts I get after each 20 runs in the first 100 runs. On average it was -1850 exalts for 20 runs in catalysts. I was selling only good ones and flipped other ones. From my perspective, catalysts’ income would cover 50-70% of a run, because I rarely was selling divines and other stuff to get more fragments.

Regarding profit, you can check the table below—it’s OK, around ~80-90 div, with a 1.4 ex price per fragment.

If you want to run it, you can copy the table, set all current prices, and decide.

One more thing to mention—I think Xesht has around a 5% drop rate of unique gems, and it just decides what gem to drop at the same moment. So I don’t think it’s correct to set a drop rate for each gem separately. I know it’s 1.25%, but you usually look for a chance to !ding! in general, so…
