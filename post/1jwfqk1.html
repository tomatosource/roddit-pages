Anybody else feels like this game had d4 syndrome in its skills

First of yes I know it’s early access and there a lot of skills not in the game however I’ve noticed persistent issue when trying to come up with builds . That issue being the skills being designed in a way that forces you to build them in a very specific manner for them to be effective for example with whirlwind it has interactions for ground effects and whirlwinds and it pigeon holds you into building into whirling slash because whirlwind is such a specific mechanic that only 2 skills use . Other examples include explosive spear which has specific interactions with detonation skills and if you want to use that well your heavily pushed into using other detonations skills .

Stuff like this feels very restricting towards build making which combined with the weapon restricted skills limits build variety compared to competitors like last epoch and also path of exile 1 .
