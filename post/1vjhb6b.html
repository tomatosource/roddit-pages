Another Speedrunning Tool - Autosplit script for LiveSplit

Hello Everyone,

TL;DR: I made a speedrunning tool, you can find it here https://github.com/ScottHoppe414/Path_Of_Exile_2_SpeedRun_Tool/tree/main

Please for the love of all that is holy, read the READMEs. They give a bunch of good info, not only on how to install the different modes, but how to use them as well. The READMEs also talk about what the modes are intended to do.

I wanted a speedrunning tool because I wanted to practice for the race event. Well, I wanted to use the good old-fashioned low-profile LiveSplit. But wouldn’t you know it, I couldn’t find an easy-to-use autosplit setup that did what I wanted. So, I made one (inspired by SavageOranges’ autosplitter). His autosplitter uses a DLL-based LiveSplit component which allows for native integration with LiveSplit and user friendly options like drop-down menus and such. I decided to go with an ASL (Auto Splitting Language) approach. ASL is essentially for making scripts.

The script approach made it easier for me to iterate on my ideas involving custom route behavior and configuration files without having to maintain a LiveSplit component, but at the expense of user-friendliness, as you have to do some manual file setup (if you read the README, you will know why). But in the grand scheme of things, it’s not all that complicated, mostly just copy and pasting some files. Anyway.

I have some other features planned but they are a little tricky to implement and if I can get them working, hopefully (in conjunction with LiveSplit) this will be more than just a simple PoE2 autosplit speedrun tracker, but a more complete PoE2 speedrunning toolkit.

If you guys have any suggestions, ideas, or bug reports head over to the github issue tracker. If you want to add to the project please feel free to make some pull requests.
