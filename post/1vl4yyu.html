Updated to user friendly AutoSplitter for LiveSplit

Application here: https://github.com/ScottHoppe414/PoE2RouteAutoSplitter

I’ve taken some time to update the application I’ve been working on for speedrunning and I feel like I’ve made some progress. Right now it is an accessory to LiveSplit so show them some love too; it is a great application for speedrunners in general. One major limitation to this right now is the fact that it is a Real-Time tracker only. I am working on a Game-Time tracker, but its tricky. Real-Time means it simply runs non-stop, so loading screens, cut-scenes and other systems do not automatically pause the timer. I’ll post the game-timer feature once I get it in a reliably working state.

The current features are:

  1. Area completion: you use predefined routes, custom routes, or play as you go (dynamic) routes. Splits automatically trigger when you enter a new area, the assumption is you “cleared” the prior area. The route ends when you enter your final area, the default is the Ziggurat Refuge.
  2. Boss kills: Predefined lists, custom lists, and play as you go (dynamic) lists
  3. Combination of area and boss lists
  4. A user friendly UI that lets you easily select the route you want or build/edit your own, export the list and appropiate script to LiveSplit and go.
  5. boss watcher: a custom program that watches for boss health bars and automatically splits when a boss dies. (technical note: the watcher is an OCR program that only watches for when the boss bar leaves the screen. This can happen for reasons other than death. If a false split happens, LiveSplit has an undo hotkey and that this script utilizes. It is up to the speedrunner to undo false positives.)
  6. Level race: Defaulted to lvl 100, but can be set to any target level

I’ve spent quite some time on this project and I’d love to have any feedback or suggestions for future updates.
