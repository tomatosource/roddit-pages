Controller support needs to step up

I like playing games like poe 2 with a controller, its also the most effective way for me because I have a problem using the keyboard, however in games like this I switch back to my mouse when I want to manage inventory or trade because I find it very hard to manage with a controller, it is possible of course, it’s not that bad but let’s just say that I find it overwhelming to manage with a controller and I guess it gets even worse on higher levels. This is not possible in poe 2, if you have the controller UI then your mouse is almost unusable, you have to logout to change the input, I don’t like the controller UI either. There is also one more thing than I don’t like, on controllers the B button has always been confirm while the A button is back/close, on poe 2 these are opposite and it’s really weird if you have been playing with controllers for years. There isn’t an option to change it.

Considering that my Azeron mouse feels very bad with isometric games, I guess I’m stuck to play with my 3 button mouse again which is not great especially since you are not allowed to keybind the mousewheel either, I can manage with a minion class but I want to do more things this upcoming league and the controller really allows me to do much more, the rolling/kiting is more smooth, I can play more classes, etc. I can use lots of skills…
