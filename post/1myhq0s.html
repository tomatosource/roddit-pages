Enable 32:9 Ultrawide - Black Bars in 2025? (Please!)

Hi GGG,

I’m writing to request that you reconsider enabling 32:9 ultrawide support in Path of Exile 2. Currently, the game supports up to 21:9, but artificially restricts 32:9 displays, which is frustrating for those of us who’ve invested in these monitors.

I understand the stated reasoning is about “unfair advantages” in races, but I’d like to respectfully challenge this logic:

1. Racing is an extremely small part of the game Let’s be honest - what percentage of the playerbase actively participates in competitive races? 0.1%? Maybe less? Why should the entire playerbase with 32:9 monitors suffer for an edge case scenario?

2. The “advantage” argument is inconsistent If wider FOV is such a game-breaking advantage, anyone serious about racing could just buy two cheap 27” monitors and achieve the same result. The barrier to entry is minimal. By this logic, should we also:

  • Cap framerates because 240Hz monitors give an advantage over 60Hz?
  • Throttle CPUs because better processors load zones faster?
  • Restrict graphics settings because lower settings might show mechanics more clearly?

Where does it end?

3. Third-party tools already enable it The fact that unofficial tools can unlock 32:9 support proves the game can handle it technically. I don’t want to use third-party tools and risk my account, but it’s frustrating knowing the capability exists but is artificially locked.

4. It’s 2025 32:9 monitors are becoming more common. Supporting modern display formats should be standard, not something we have to beg for.

I’m simply asking that you trust your players to make their own hardware choices. If someone wants to race competitively, let them decide if 32:9 is a must have or not.

Please consider enabling full 32:9 support. Those of us with these monitors just want to use them as intended without black bars.

Thank you for considering this request.
