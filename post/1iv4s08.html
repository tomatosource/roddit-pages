I discovered something weird in PoE 2. The only other game I have been able to recreate this is Elite Dangerous: Odyssey where I cannot even play through the entire tutorial, it will crash at the same spot. Every other game runs stable.

If I set dynamic resolution off in PoE 2, my system shut downs at specific in game events, more specifically when Balbala does the poison thing but I haven’t tested other events so there are probably more. If I leave it on, everything is fine and I play at 144fps stable. It’s not a cooling/temperature safety shut down either, CPU will be in the high 60’s when it occurs.

I know this is a CPU/PSU issue because my AMD configurations doesn’t auto reset like they will in a GPU driver crash. A full sudden shut down usually indicates a power delivery failure aka a faulty PSU, so what I naturally did was run a 100% power draw test with OCCT. 650W for my system is slightly underpowered but is well within max power draw specs. Anyway, the PSU test is stable and can run indefinitively without crashing.

I’ve read off the cuff somewhere on the internet that there is a specific issue with my processor where some erroneously coded games will ask for 101% power draw to the CPU which causes a safety shut down.

Anybody else experienced this? Thought it would be worth documenting at least.
