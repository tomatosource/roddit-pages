Thoughts on PoE2 Passive Tree

EDIT: Too many comments saying PoE1 and PoE2 are different games, why compare them? I made the comparison not because I want to make PoE2 the same as PoE1. I understand that PoE2’s monster HP and damage calculation is different from PoE1. PoE1 is just a reference point to me, not the target. I made the comparison It’s because I think PoE1 tree provides good amount of deterministic scaling during the progression, and it feels fun and impactful to play around the tree, even at late game. PoE2 can get better on it. It’s a different game, but it doesn’t mean PoE2 can’t learn a thing or two from PoE1.

============================================================

Everyone talks about how weak PoE2 passive tree is. I totally agree, but I am also curious how much weak it is. So I did some comparison between PoE1 and PoE2 passive tree. Here is my findings.

As of patch 0.3 in PoE2, you can allocate 122 out of 3447 nodes (122⁄3449 = 3.54%). While in PoE1, you can allocate 123 out of 2237 nodes, mastery included (123⁄2237 = 5.50%). PoE1 can cover 50% more nodes of the passive tree.

  • This is understandable that PoE2 has more nodes because it has more weapon types, it has more classes/ascendancies
  • The ratio will get worse when new classes are added.
  • It might not be an issue if each node can provide more or less the same power. Unfortunately, it is not the case, which leads to my next point.

PoE2 node is generally 30%~50% less power compared with PoE1 node. I picked some of the nodes to compared.

  • Bow node
    • PoE1: King of the Hill: 100% increased critical chance
    • PoE2: Sniper, 60% increased critical chance if 7 meters travelling
  • Axe node
    • PoE1: Cleaving: 30% increased phys, 30% increased ailment, 15% chance to intimidate
    • small nodes grants: 12% increased phy damage and aliment, 3% increase attack speed
    • PoE2: Whirling Onslaught: 50% chance to gain Onslaught on Killing Blow
    • small nodes grants: 3% increased attack speed only.
  • Of course there are nodes that PoE2 are better, but it is very rare. For example, some of the elemental penetration nodes are better in PoE2.

=====================================================

To make the PoE2 passive tree better. Simply reducing the nodes won’t work. I have 3 proposals

  1. Buff the node generally. It is the brutal force one, can be a short term solution.
  2. Grant more points to player, make level 100 character to have 150-180 points. It will definitely bridge the gap. It also can make the build diversity better since each class can travel further on the tree.
  3. Redesign the passive tree by adding the gateway point at the edge of the tree, so player can use gateway to skip some travel points. It’s also an interesting idea to make a 2-layer tree, with some gateway to connect between 2 layers. This way, you can pack more point within each class quadrant, and let player cover more distances within the same amount of nodes.
