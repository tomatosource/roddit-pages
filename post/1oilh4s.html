Leveling up from 98 to 100

As the league is wrapping up, I set a goal for myself: get my main (LA Deadeye, I know 😅) to level 100. I’m currently sitting at 98, and the progress is painfully slow. At this point, I don’t even care about loot anymore. I’ve got around 300 divs just sitting in the stash with nothing I really need to spend them on.

So I’ve switched focus entirely to XP farming using XP tablets. My process right now is: I fully 6-mod all my maps, instill for pack size, and then corrupt them. Roughly 1 in 8–10 turns into a T16, which I’m saving for the 99→100 push. The rest, if they’re 50%+ pack size, I run with 3 XP tablets. If they roll lower than that, I list them for ~2 exalts, and they usually sell almost instantly.

For tablets, I’ve been managing to self-sustain +15% XP gain ones so far, but I’m starting to run low. So I’ll probably need to either buy more or settle for lower-quality ones soon. With this setup, I’m getting about 7–8M XP/hour, which means it should take around 30–40 hours to hit level 99.

I’m curious, is this considered efficient? Do any of you approach endgame leveling differently? And is it worth running Expedition logbooks for XP at this stage?
