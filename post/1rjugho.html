Introducing the PoE Acronym Bot

Hey exiles,

We’ve built a bot for this subreddit that explains acronyms and common terms. Path of Exile has a lot of jargon and it can be rough for newer players to understand every term that comes up.

How it works:

When a new post contains acronyms (DPS, DoT, PoB, etc.), the bot will reply with a quick reference of what each one means and add a wiki link if one exists.
In comments, you can use bracket syntax like [AoE] or [Headhunter] to summon the bot. The bot will reply with definitions for known acronyms and search the wiki for unknown ones and if there is no acronym it will look for a wiki page with that name.
The acronym database is synced from the https://www.poe2wiki.net/wiki/Guide:Community_shorthand wiki page occasionally and after curation, so it stays up to date. If you want to add an acronym, the best way is to add it to that wiki page directly.

A few other things

  • If a bot reply isn’t helpful, just downvote it. Replies that reach some downvotes are automatically deleted.
  • You can browse the full acronym list or suggest additions at: https://acronym.sidia.net/acronyms/pathofexile2
  • Editing in tags will not trigger the bot
  • The acronyms list will have small mistakes until we refine it, we fix them as we see them, feel free to ping u/KadekiDev if you spot a mistake

Feedback and Term suggestions are welcome!
