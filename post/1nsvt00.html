Best/worst maps in PoE2 (WiP)

I was on a little project lately to evaluate every map by very particular criteria and put them in the list to see exactly how bad or good they are (for my personal taste). Mostly out of curiosity, but also to help me remember where to use my best waystones, and which maps to skip completely. Anyway, this is how the list looks so far (sorted from best to worst):

https://preview.redd.it/1e66lvdg5yrf1.jpg?width=958&format=pjpg&auto=webp&s=f4e82df941c2c85124cd562fc9a053d1fdcf1a94

https://docs.google.com/spreadsheets/d/100ht7mvD6hIl-RhbIgr0ZCHEdlkNCfQLPHJ6nXouhXo/edit?usp=sharing

  • “bad layout” - Layout bad for clearing and/or hosting encounters like breach, ritual and whatnot. 1 = so-so, 2 = bad, 3 = terrible.
  • “obstacles” - Doors to open, levers to pull, natural hazards, delayed spawns, multiple floors and stuff like that. 1 point for each different type of obstacles. Extra point(s) for especially annoying obstacles.
  • “low mob count” - I didn’t actually count them, but to me it’s pretty damn clear if a map with decent juice feels half empty. 1 = kinda low, 2 = very low.
  • “shitty boss” - Long animations, multiple phases, weird/separate arena, or just surpisingly rippy. Any of this can cause 1 if I feel strongly about it, but no more than that.

Some maps are probably missing and some bosses I simply can’t remember.
