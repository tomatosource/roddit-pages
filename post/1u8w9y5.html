PoE2 Trade Copy Button - Chrome and Firefox extension

Hey peeps. I just recently added an extension to both Chrome and Firefox “stores” that adds a copy button back to the PoE2 trade website. It uses the new “Advanced Copy Paste” format that was made standard in 0.5. So the mod dropdowns get populated with the proper mods, same as if you copied it directly from in game.

Theres a few extensions with the same name, didn’t really think about that. But I have the links here, as well as to the github (newest version is 2.3, so I need to update github release). It was mostly vibe coded as I have no background in JS, so feel free to judge harshly on how it’s done. I will let the robots know your opinions.

Also, please make an issue on github if you encounter anything. Some bugs may be PoB side as we just recently added support for this new advanced copy format, but either way I can take a look at it. :)
