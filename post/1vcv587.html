New open source TypeScript library for POE2 tools

I’m not sure if posts like this are allowed, but I think it fits better here than in general programming subreddits.

I’ve just published a pre-release version of a new TypeScript library that aims to make it easier for other developers to build POE2 tools and web apps: https://github.com/mortenscheel/libpoe2

Full disclosure: Most of the library was written with Claude Code (Opus 5). I could probably have written it by hand, but honestly I don’t think I could have done a better job.

Everything is documented in the repository, but here’s the TL;DR:

  • Item database with almost every in-game item.
  • Tools to resolve item mod pools, mod weights, tiers and descriptions.
  • Passive skill tree (and ascendancies) graph and support for finding the shortest path from A to B.
  • Skill gems: which support gems fit this skill.
  • Economy: fetch prices from poe.ninja (their rules and rate limits are enforced by the library to prevent abuse).
  • Item artwork is not included because I’m uncertain if it would violate GGG’s terms.
