Bonestorm is my favorite ability so far in POE2 so I started the season wanting to play Physical Spell Lich.

I enjoy this build a lot. For a long time I was using bone cage with CoC DD to map, but got bored so wanted to try to make mapping with bonestorm work. It’s ended up at least as good if not better. Probably a little more prone to stun lock so added some stun threshold in tree.

I swap 2 supports out on bonestorm for bosses since I dont need the one tap there and scattershot post nerf is really not worth it when I want max DPS. This is through a lot of testing to DPS check on T4 Pinnacles. Quickest I can do T4 is like 30-40 seconds, trying to get this lower.

Mapping outside of breaches is crazy easy. Mana Tempest Bonestorm with a few power charges absolutely clears screens. If I dont proc my CoC for profane Ill use a quick siphon in between casts.

Biggest realization I had is Blasphemy with Temporal Chains &gt;&gt;&gt; Enfeeble or Vulnerability.
