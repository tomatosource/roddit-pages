Problem: Pathing between atlas nodes. Solution: Delve.

Okay now HEAR ME OUT.

We’ve all been in the situation where we see an atlas node we want to run, but there are map nodes we are less excited about between here and there. What if we could tunnel to them?

We would pay an upfront cost in Sulphite to have Niko chart us an underground path to the node we want to go to. Naturally, the farther you go, the more Sulphite you’ll need to fuel the drill cart, and surely GGG could come up with something clever here regarding different types of encounters depending on distance or surface nodes you’re skipping (multiple phases, difficulty, objectives, cave biomes, chamber types, etc).

If you survive the encounter(s), congratulations, that distant map node is now unlocked and you can run it and progress your atlas from there. If you fail, well, tough luck, you’ll have to try again once you have enough Sulphite.
