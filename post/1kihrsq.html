Dodge Roll Feedback

More I play, more conent I watch, more I dislike Dodge Roll implementation in POE 2.

The issue I have is that there is no cooldown and combat is somewhat balanced around that fact and I don’t think it’s fun. Basically we are “forced” to use it almost all the time, to dodge stuff or to animation cancel.

Look, I am glad we have dodge roll in game but I would prefer if GGG buff the overall defensives, slap 10 sec cooldown on dodge roll so we only use it for BIG attacks (boss fights, etc).

P.S. I know some builds do not suffer from this issue that much, but many builds do (Maces for instance).
