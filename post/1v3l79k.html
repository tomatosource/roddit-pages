I made a Japanese version of Path of Building for PoE2 (free, open to everyone)

Hey exiles! Long-time player from Japan here (~1,100 hours this league).

PoE2 finally has an official Japanese client, but all the community tools are still English-only. The biggest pain point: if you play in Japanese, you can’t copy-paste items from the game into PoB because the parser only understands English text. That meant Japanese players couldn’t do the most basic thing — checking if a weapon on trade is actually an upgrade before spending divines on it.

So I built a Japanese version: poe2builds.app

- Full Japanese UI using the official localization data extracted from the game client, so all mod/passive names match exactly what you see in-game

- Copy items from the Japanese client and paste them straight into the build — DPS/EHP comparison just works

- Stays in sync with patches since translations come from game data, not manual translation

It’s completely free. I mainly made it for myself, but I figured the Japanese community deserves proper tooling too. The JP player base has been growing fast since official localization, and I hope this lowers the barrier for newer players to get into buildcrafting.

Feedback and bug reports welcome!
