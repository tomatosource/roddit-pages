Infusions feel like an Ascendancy Class mechanic rather than a core system for Sorc skills.

I don’t ever see a scenario where these skills can “Feel good” because they’re going to be a nightmare to balance, unless the Infusion system is locked behind an Ascendancy.

Either the non-infused version is going to feel too weak and therefore infusion/combo gameplay feels mandatory.

Or the non-infused version is already strong, and thus the infused version doesn’t feel impactful enough and then there’s really no point in it even existing.

It really does feel like it needs to be a secondary system, behind an Ascendancy Class, so that the Skills can be balanced properly, before the Infusions are then balanced separately behind the Ascendancy Class.
