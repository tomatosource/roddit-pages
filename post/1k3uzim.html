End Game Mapping Improvement

A common problem I’ve had while mapping is running into a string of the same map while pathing to specific areas (corruption or towers). If this is a map or layout you hate it can really kill your desire to play.

My solution to this: As it is now, the end game map rolls biomes to procedurally generate the map and then randomly selects maps available in that biome. What if it only rolled the biomes and gave the player the option to select a map from that biome when placing a waystone. For example, say you had a grass biome as your next node. The game would then give you the option of Augury, Blooming Field, Bluff, Crypt, Decay, Hidden Grotto, Savannah, Seepage, Steaming Springs, Steppe, or Vaal Factory when you insert a waystone. This would really help to alleviate a lot of the “sameness” while mapping and give the player some agency.
