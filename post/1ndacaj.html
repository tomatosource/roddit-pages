0.3 Mace Skills Feedback

After the announcement I was pretty sceptical about mace skills and warriors in particular. Partly because of the block change (and it really feels worse than before), partly because there was no change to the armour formula or any solution to the life problem.

But it turns out that maces and warriors are in a good spot right now. Not the fastest clear nor the 80m one-shots, but it’s safe to say you can be very efficient in endgame. Armour starts to shine if you really invest in stacking it to the point that you almost take no damage from most abilities (300–400k armour applied to elemental damage is REALLY strong).

tldr; Mace skills have several QoL problems that still not been addressed. Such as dodgeroll animation cancelling, fissures not created if targeting closed objects, 2H over 1H.

I think it’s better to address some clunky skill interactions and overall problems.

For example: you cannot create fissures if you are targeting a nearby object. This is insanely frustrating on narrow maps or maps with a lot of decor.

Abyss pits is \“an object\” as well btw

Not only Earthshatter, but also Volcanic Fissure. Pretty sure Quarterstaff fissures too, and maybe even more. The problem is that with the current lack of visual clarity you don’t notice it instantly and sometimes this leads to death. For example Sunder travels through objects with no problem.

Animation cancelling with dodge roll is still a big part of mace skills usage. Leap Slam, Stampede, Boneshatter, Shield Charge you cannot use them in combat without dodgerolling, because the 0.2-0.3s windout animation is dangerous. That windout animation should also be interrupted just by using any other skill in sequence.

Forge Hammer - a great addition to the mace toolkit. Ambrosia consumes mana flask charges when you return the hammer to your hand (probably a bug). Forge Hammer effect is cool as hell. However, visual clarity is non-existent. It needs tuning down. Don’t get me wrong, I like how it looks, but I can’t see a quadrillion on-death effects and degen zones.

https://reddit.com/link/1ndacaj/video/am4xs3hh4bof1/player

Ancestral Cry - too many conditions. Again, the visual aesthetics are great, but you need to invest in so many things just to be able to press it. And again we have the ignite flammability paradox: flammability scales from the initial hit, so the best way to ensure strong flammability is a strong bonk but if you already bonk hard, you don’t need flammability and ignite. So the damage boost potential from Ancestral Cry is already not that strong, because you already hit hard. If you don’t, then you’ll stack flammability slower, which leads to less Ancestral Cry usage.

Boneshatter - the default support gem the game suggests is Stoicism. In a game where you cannot play mace skills without dodgeroll cancelling animations, the support requires you not to dodge roll (and therefore not sprint either) for 10 seconds. Boneshatter’s best combo is Leap Slam, which is a travel skill. Funny enough, the class that most uses this support is… Deadeye of course.

Supercharge Slam - channel time is still not scalable. Right now, according to Ninja, only ~85 people are using SCS as a main skill. I cannot understand WHEN to use it. A 5-second channel is longer than stun duration on bosses. A 2-3 second channel to kill rares is unusable because of the quadrillion effects you need to dodge. The concept is great but you can’t even walk while channelling.

While mace skills are not in a bad spot, I want to address the Giant’s Blood problem. You are forced into using a shield unless you stack 50k+ armour and 150-200% apply to elemental (which is not as hard for Titan as you think). And since 2H provides more DPS while also having better utility mod tiers (Aftershock 25%, etc.), people will always lean toward Giant’s Blood even with the life penalty (which I find strongly unthematic). 1H maces should provide some unique utilities to compete with 2H. Maybe allow using skills while moving or better utilisation with APS.

Titan with a 1H mace is my 2nd character this league and I am pretty happy I tried it.
