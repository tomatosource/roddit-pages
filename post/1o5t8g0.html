Weapon set points disappearing after applying them. Is this a bug or me doing something wrong?

Hey all — I’m running into a weird issue on Xbox (console) while building my passive tree and allocating weapon set points (for weapon set 1 / weapon set 2). I’m using a two-handed weapon, and here’s what’s happening:

What I do:

I allocate points to either weapon set 1 or weapon set 2 in the passive tree UI.

I hit “Apply” (or accept changes).

Initially, the allocation seems to take effect: I exit the passive tree, play a few maps, etc.

Later, when I return to the passive tree, all the points I assigned have been removed or reverted to a prior state.

What I think / what I found:

Several players report that “weapon set skill/weapon set points” reset themselves after entering a map.

One workaround people mention is: “first refund / clear your changes, apply those, then exit the tree UI”. After that, reopen and allocate your weapon set points. Doing the refund + assign in one go sometimes triggers the bug.

Another tip is: wait to level up (i.e. have an extra unspent point), then do the respec / allocation so the system has “breathing room.”

Some threads also suggest this is a known bug, not just user error.

Questions for you folks:

Has anyone else on console (especially Xbox) had this happen reliably?

Is there a “safe order” or sequence (refund → apply → exit → reallocate) that always works?

Is this something GGG is aware of / actively fixing?

Thanks in advance — this is driving me up the wall.
