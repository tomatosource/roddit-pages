Dear GGG, I think the best way to fix crafting would be to add a new Omen called “Omen of Last.”

When this Omen is active, using a Chaos Orb would re-roll the item but keep the last modifier that was previously added by an Exalted Orb. This way, players won’t be afraid of “breaking” an item and can keep using Chaos Orbs until they get the modifier they want, without losing the one they already invested with an Exalted Orb.

Yes, I know this system could feel strong, but it can be balanced. To keep it fair, it should only drop in the endgame and be very rare, so players can’t easily find it.
