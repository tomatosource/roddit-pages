[New] Sofa Exchange 2

I’m a PoE2 console player, and for a long time I’ve felt there’s a noticeable gap in trading support between console and PC when it comes to participating in the economy.
PC players benefit from tools like Exiled Exchange / Awakened PoE, which greatly simplify pricing and trading, while console players don’t really have equivalent options. This isn’t a criticism of PC players — it’s more about console players lacking accessible tools that help us keep up economically.

That’s what led me to experiment with a workaround.

The result: Sofa Exchange 2 — price items easily from the comfort of your couch (very much vibe-coded 😄).

The idea is simple:
You dump all the items you want to price into a public stash tab, then access them through Sofa Exchange once the server has synced. From there, it functions very similarly to Kvan7’s Exiled-Exchange-2 in terms of pricing and comparison.

I personally run Sofa Exchange 2 on a Raspberry Pi and access it through my phone’s web browser, which makes it feel very natural as a console player.
You can also install it as a PWA on your phone by going to the website → share → Add to Home Screen, which makes it feel almost like a native app.

The project itself merges ideas from two existing tools:

  • micahriggan’s poe2stash — for accessing items via public stash tabs
  • Kvan7’s Exiled-Exchange-2 — for the rich item pricing and comparison capabilities

Source code is available here:
👉 Sofa-Exchange-2

This isn’t meant to replace PC tools or argue about advantages — it’s simply an attempt to bridge the gap and make trading more approachable for console players using the tools we have available.
