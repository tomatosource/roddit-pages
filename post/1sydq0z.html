Weapon sets should allow for two different sets of equipment, not just weapons

Currently the Weapon Set systems only allows players to swap between items in the left and right-hand weapon slots. It does not allow us to use different rings/boots/armor/etc. for each weapon set. This limitation seems arbitrary. Weapons Sets should instead be “Gear Sets” and should allow the player to swap between different weapons/helmets/boots/rings/etc. The locking feature should also be extended to each individual equipment slot, so that the same boots, for example, could be used in both sets if desired.

This would allow players to assign gear that maximizes for damage to Weapon Set 1 and different gear that, for example, increases move speed or item rarity to Weapon Set 2. This would encourage more players to actually engage with the weapon set system.

I also posted this on GGG’s early access feedback page: Early Access Feedback - Allow assignment of different gear for each weapon set instead of weapon slots only - Forum - Path of Exile
