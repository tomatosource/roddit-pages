Ember Fusillade + Sire of Shards stealth nerf? Build destroyed after patch

So, I was running an Ember Fusillade build using Sire of Shards for the +4 additional projectiles.

Before the patch, Ember Fusillade would target enemies normally, and the extra projectiles from Sire would basically line up in the same direction.

This made the skill actually work clear felt smooth, and even bosses could be hit by multiple projectiles if positioned correctly.

After the latest patch, Ember Fusillade no longer aims this way.

Now, when using Sire of Shards, the projectiles are fired in a radial circle around the player instead of towards the target.

Clear is still ok, since you cover the screen.

But single target is completely destroyed, since only one or two projectiles hit the boss.

I noticed the patch notes only mention a fix related to Wildshards, but apparently this “fix” changed Ember Fusillade’s interaction with any source of additional projectiles, including Sire of Shards.

This feels like a stealth nerf that killed an entire build archetype without any mention.

Was this interaction really unintended? Or is this a side effect of the Wildshards fix that wasn’t communicated properly?

Either way, it basically makes Ember Fusillade + Sire unplayable for bossing.

Would really appreciate clarification from GGG, was this intended, or an oversight?

Edit: I’m seeing other players reporting the same issue with Sione’s Temper.
So it’s not just Sire of Shards it looks like Ember Fusillade’s entire interaction with projectile-granting items was reworked.
If this is intentional, it’s a massive stealth nerf that wipes out multiple builds across different uniques.

Edit 2: I want to highlight that Ember Fusillade’s skill description explicitly states that all Brasas aim for the last targeted enemy, and multiple Brasas will attempt to hit different enemies.
The patch completely breaks this intended behavior when using any projectile-granting item (Sire of Shards, Sione’s Temper, etc.).
This isn’t just a minor tweak — it contradicts the skill’s own description and kills the viability of builds that rely on precise projectile targeting for single-target damage.
Feels like a stealth nerf that was neither communicated nor intended by the skill’s design.
