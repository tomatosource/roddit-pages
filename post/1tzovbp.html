I made a browser extension that adds tier pickers to the trade site so you stop guessing breakpoints

Got tired of the loop where I want to search for like T2+ phys damage on a weapon but first I have to go look up what number that actually is, then type it into the min box, then do it again for every other mod I care about. And don’t even get me started on flat damage mods where you have to average the two rolls yourself.

So I built TierFill. It’s a browser extension (Chrome + Firefox) that adds a little tier dropdown to each stat-filter row on the trade site. You add a mod the normal way, pick a tier from the dropdown, and it fills in the correct min value for you. No more breakpoint spreadsheets or second tab with PoEDB open.

https://preview.redd.it/dh63mfybkx5h1.png?width=1280&format=png&auto=webp&s=610f5b359131f4c554ec1eb22667620c2a570068

What it does:

  • Adds a tier picker next to the MIN box on stat rows it has data for — pick T1, T2, etc. and it fills the number
  • Handles the “Adds X to Y” flat damage mods automatically (does the averaging math so you don’t have to)
  • Has Inclusive and Strict modes — Inclusive catches everything at that tier or better, Strict is more precise but won’t catch lucky lower-tier rolls
  • Badges each mod on your search results with its actual tier and roll quality so you can instantly see if a result is hitting your targets or not
  • Works alongside other trade extensions, doesn’t break anything

What it doesn’t do:

  • No pseudo mods, implicits, rune mods, crafted, enchants — only explicit prefixes/suffixes on weapons, armour, jewellery. Rows it doesn’t have data for just stay as normal number boxes
  • Doesn’t automate searches or hit GGG’s servers at all. You still click Search yourself
  • Collects zero data, makes zero network requests, everything is local

It’s open source (MIT) and free obviously: GitHub

Install:

  • Chrome / Edge / Brave: Chrome Web Store
  • Firefox: Firefox Add-ons

If you run into any bugs or have suggestions, issues on GitHub or just reply here. First release so there’s probably stuff I missed.

Edit: Right now it only supports PoE 2, but planning to add PoE 1 support soon.
