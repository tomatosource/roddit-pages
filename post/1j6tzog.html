Instead of deterministic crafting I’d love to see more deterministic farming and an expansion of the tiered rares system.

I played Poe 1 from tempest to abyss and have a lot of love for it. As they added more and more leagues though it became a game I lost interest in learning. Keeping up with all the new league mechanic crafting holds no interest for me. I want to find loot not deterministically craft it.

I know a big complaint about PoE 2 is the lack of this sort of crafting, but I really hope it stays this way. I want more incentive to pick things up, ID them, slam them etc not less. Watching Empyrian still picking up bases and rares occasionally was really refreshing when this game launched.

I’d love to see an expansion of the biome target farming type of system the node Local Knowledge adds. Maybe with some way to have more agency over what biomes we’re farming and what items they give bonus drop chance to.

The tiered rare system is also a great idea that should see some more love. A boss dropping a high tier weapon type you can use should be more exciting. It’s not bad as it is but maybe tier 5 is too low of a cap or higher tiers should also have different mod weightings.

Any thoughts on how to make farming better instead of crafting?
