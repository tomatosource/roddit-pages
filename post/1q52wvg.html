If you’re a Wolf and you use Weapon Swap to prolong Lunar Blessing, you can get 10+% Skill Speed for free by using Amor Mandragora

Just dropped it in SSF and it seems to work

Amor Mandragora is a unique talisman which grants Druidic Prowess per 20 rage spent. Each Druidic Prowess is 10% Skill Speed for 10s (up to 3 DP). Weapon also gives static 10% skill effect duration which works nicely with prolonging Lunar Blessing

You can just slot it into whatever weapon slot you use for buffing Lunar Blessing uptime and, since it uses rage, you’ll get 1 stack of DP or 2 if you get max rage to 40+

Not a killer feature but not too shabby either
