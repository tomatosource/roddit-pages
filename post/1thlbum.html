Weapon swap is OP for utility, but underwhelming for dual element/weapon sets. My suggestions.

When the Weapon Swap mechanic was introduced in PoE 2, my fantasy was to, lets say, jiggle between the weapon set 1 with a fire staff + 24 fire passives allocated and the weapon set 2 with a cold staff + 24 cold passives (or different weapon archetypes for martial weapons), but there are some problems with that.

Problem № 1:

There are some nodes on the tree, which give powerful bonuses (like exposure/curse/shock effect), which can affect your 1st weapon set, while using them in the 2nd weapon set. So, why bother trying to make double element builds to work, if instead I can go full damage in the 1st set and take all the exposure/curse effects in the 2nd set, effectively giving my singular element build +24 extra passive skill points, which is WAY more effective?

Suggestion:

Make these nodes hybrid, which give damage/speed/defences alongside their usual effects, but with weaker multiplier (similar to how hybrid nodes give +12% ES+evasion, while pure evasion ones give +15%). This will make these nodes usable in both weapon sets, while reducing their effectiveness for a pure 2nd slot utility use.

Same story with parry nodes. Instead of only using a buckler in the 2nd slot with all the parry nodes, make these nodes give parry effects + damage/speed/defences while using a buckler. This way, I can still invest into all the parry nodes without losing too much effectiveness of my spear setup, while making my set 2 more flexible, so I can occupy it with a grenade launcher or smth.

Melee builds? They tend to only use a single weapon with 2 different passive skill sets, filling the 1st set with all the damage nodes and the 2nd set with all the area of effect nodes, which is very effective for clear, but… quite boring and limited? Why don’t combine Area Damage and Area of Effect nodes, but with slightly weaker effect? This way, they will apply both for bossing and mapping, giving players more freedom for the 2nd weapon set.

Problem № 2:

(This will be related to the problem № 3, so please BEAR with me).

Many of my build tend to look like: 6 different 30-spirit reservation skills, 1 mobility skill, 1 utility skill and then FINALLY my main skill. And I would LOVE to experience an actual combo gameplay, but how can I do that, if most of my gem slots are occupied by buffs/auras?

Suggestion:

Make separate limits for active skills and reservation skills, giving active skill gems a limit of 5-7, while giving reservation skills… no limit at all? I mean, it’s already limited with the amount of spirit we have, no need to limit it any further.

Problem № 3:

As an example, druid was advertised as someone who can cast long-lasting spells, which are followed by shapeshifting shenanigans, turning it into an attack+spellcaster hybrid playstyle.

But how am I supposed to do that, if all 9 of my gem slots are occupied by martial weapon reservation skills and shapeshift skills from set 1? Where do I put my long-lasting damaging spells and caster-related reservations?

Suggestion:

Make 2 gem tabs, each having a separate gem limit for each individual weapon set (where you can use the same gem in both tabs and/or use different gems for different tabs), so players can fill different weapon sets with different skills and reservations.
