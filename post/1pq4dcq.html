Easy way to apply 42% Shock or more on any class. With self shock removal as extra bonus

Minimum requirements(using minimum level gems):

- 17 Str 41 Str
- 17 Int 41 Int
- 15 Dex
- Second weapon set available(any caster)
- 2 gem slots

First gem slot:
- Thunderstorm(Applies Drenched)
- Shock conduction II(Always shock Drenched Targets)
- Overcharge (Reflect shock, 50% Increased Shock magnitude)
- Commiserate (Remove self shock to apply 40% MORE shock magnitude)

Second gem slot:
- Any skill that does hits(I’m using spark but you can use any, preferible with low cast/attack speed)
- Shock conduction II(Always shock Drenched Targets)
- Overcharge (Reflect shock, 50% Increased Shock magnitude)

Important note for thunderstorm:

You will need to reach level 18 skill gem to remove the level restriction that it have to apply drenched to monsters.
To do it, a easy fix it to use any staff with +7 to lightning skills or want + focus with + levels. So If we have a +7 we will only need level 11 gem so it’s much lower attributes than using a level 18 gem.

How to apply the 42% shock:

First, set Thunderstorm and second skill to be used only on set 2, and your other skills on 1.

Cast Thunderstorm to apply Drench -&gt; Use second skill-&gt; Cast Thunderstorm

How it works:

The second skill will always shock thanks to Shock conduction II because the enemies are Drenched from the first cast of Thunderstorm. This makes that the shock will be reflected to us.

Then when we cast Thunderstorm the second time, Commiserate will activate by removing the shock we have, and apply the 40% MORE magnitude, together with Overcharge that does 50% increased magnitude, for a total of 42% shock.

Notes:

When using Overcharge + Commiserate supports, the shock is first reflected, and then removed at the same, so every time we cast Thunderstorm it will remove our shock. This is also very good because it can also remove any shock from the enemies, so it’s another benefit of using this combo.

How to scale even more shock magnitude very easy:

As we are using a second weapon set, and we don’t care of the damage it does, be can benefit from the passive points of weapon sets.

You can keep the damage nodes on your first set, and use the 24 passive points from the second set to pick some shock magnitude if you can reach them.

I managed to reach 84% shock by using this 24 passive points to reach some magnitude points, the anoiment Harmonic Generator that also gives me crit chance that benefits my first weapon set and i always do crit with Oracle + 30% magnitude rune on gloves.

I think it can fit in any build that meets this requirements, but maybe i missed something as i only tested with my build

Tips:

You can use the pathing nodes to reach the required attributes to use the skills. As you only need this attributes to the second set, you can get a lot of them in the way.

If you can meet the requirements of the weapon attributes, you can find good rolls on cast speed to make it smother and also apply cast speed runes.

Also technically you could use a attack on the second skill, but then you will need to have a apropiate weapon for that skill on the first set, so if you already have one, you can do it, and set that attack to set 1. But if it’s confusing, the easy way is just use 2 spells on second set.
