Does anyone here play Beat the Streak?

I Built a trainer that lets you run through the 2025 season to test picking strategies. Days are randomized so you can’t memorize patterns.

Two modes:

  • Model - shows hit probabilities from a model I’ve been working on, ranked top to bottom
  • Manual - pick any player from any game yourself

Make your pick, see instantly if they got a hit. Streak ends, reset and try again.

Figured it’d be useful for testing ideas before next season instead of theorycrafting in the dark.

https://www.xwobiwan.com

Still rough around the edges so I’m looking for feedback, let me know if you hit any bugs.
