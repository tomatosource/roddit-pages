Thoughts on Tiered loot and meaningful drops in endgame

I wasn’t really sure if this had been talked about before, but i had some thoughts on Tiered loot and a commonly brought up issue of making ground loot matter.

The main problem it seems is in endgame maps (on trade at least), most/all rare items are being hidden from loot filters, because they are either not good or not worth people’s time to identify. What this means is while very rare, a very good rolled item could drop but you would never see it.

Tiered loot has been GGG’s modern solution to try to address this problem, but it still seems to have some issues. While it should be an improvement (and it probably is somewhat), some players still describe picking up Tiered loot as lackluster and i’m not sure if it fully solves the problem.

Now, while controversial, having items dropped identified would in theory solve the ground loot problem, however doing so would also cause many other problems to exist. Identifying items and the dopamine of hitting good rolls would be gone. This is a big problem. Also loot filters themselves would become almost infinite in length causing even more busywork and annoyances for many players. So in general i don’t think this is a good solution.

So, what could be done to either make Tiered loot better and to help solve the problem people have of making ground loot matter? The answer i believe lies in the system that GGG has in place of how loot drops.

It is important to say here that i would need clarification of to how Tiered loot actually works currently. When the ‘roll’ is being made that an item should drop, is it ‘rolling’ that this item should drop as a Tiered item and its ‘roll ranges’ are then being rolled accordingly OR is an item rolled first, with the server determining that it has high tier rolls on it, then being dropped as a Tiered item?

I think this is an important distinction and this leads me to a potential solution. Similar to how the Breach tree works in PoE1 where it lets you specify an Item type (body, gloves, boots, weapon etc) and then lets you select affixes you want/don’t want to see (defenses, physical, elemental, resistances etc), i believe there is a way that GGG could implement an in-game Filter that would allow players to simply and cleanly define what they want their Tiered loot to look like.

If this was done well and was implemented on GGG server side AFTER and item drop had been determined, but BEFORE it was sent to the game client, this would both allow players to keep Tiered loot on their item filters, meaning even in late endgame maps players would not want to hide said items, and more importantly and i think crucially, it would not remove the dopamine of identifying items nor would it create item bloat in existing filters.

Obviously this would need to be looked at carefully to both prevent players from knowing items dropping would be perfect while also keeping the UI interface clean and with as little bloat as possible, but i believe this might be an almost perfect solution.

Sorry for the large wall of text and i apologize if i have missed important parts in my description, but please feel free to ask any questions for clarification or comments.

Thanks

TLDR: Tiered loot becomes a simple server side filter players can setup, similar to Breach tree in PoE1. This makes ground loot worth picking up, even in late game, but also keeps identifying items intact while preventing bloat from items dropping already identified.
