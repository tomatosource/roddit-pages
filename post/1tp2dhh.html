I built a PoE2 loot filter editor in the browser - updated for 0.5 !

I’ve been quietly building a web-based Path of Exile 2 loot filter editor and wanted to share where it’s at after 2 months of active development. It’s Called AnnulFilter

Quick note: If you're happy with Neversink's tool and don't want to tweak your filter or build one from scratch, stick with it — it's excellent and covers most players perfectly. This tool is for people who want full control over every rule they write.

What it does

  • Visual rule editor with Show/Hide toggle, conditions, and action styling
  • Live item preview — see your beam, label colors, border, background, and minimap icon in real time
  • Nearby Items mode — 6 random rules from your filter rendered around the main item so you see how it looks on the ground
  • Import/export .filter files directly from your PoE2 filters folder (via File System Access API — no more manual copy-pasting)
  • Folder system with full drag-and-drop, sub-folders, and hide-all support
  • Saved Visuals presets to reuse action styles across rules
  • Advanced search across full filter text
  • Links tab: currency items link to poe.ninja, everything else to poe2db.tw
  • Custom alert sounds via CustomAlertSound

I’d love feedback, bug reports, or feature requests.
