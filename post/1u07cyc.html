Potential fix for the infinite shader compilation bug (Nvidia users)

Hey guys,

If clearing cache folders, switching between Vulkan/DX12, or setting Shader Cache Size to Unlimited in Nvidia Control Panel didn’t work for you, try this.

After digging around, I found a weird conflict that turned out to be the root cause in my case. Turns out, the NVIDIA driver completely confuses PoE 1 and PoE 2 because GGG named the executables exactly the same (pathofexile_x64steam.exe). For some reason, the driver gets locked into the old PoE 1 profile, bugs out, and stops PoE 2 from properly saving its cache files.

NOTE FOR DUAL PLAYERS: If you actively play both games, this might reset your custom Nvidia Control Panel settings for the first game.

To fix the profile conflict, you need to use Nvidia Profile Inspector (a well-known open-source tool available on GitHub).

Step 1: Clean up the PoE 1 Profile

  • Open the tool and search for “Path of Exile 1” in the Profiles bar.
  • Look at the file badges under the search bar.
  • Remove “pathofexile_x64steam.exe” and “pathofexilesteam.exe” from this profile.
  • Click “Apply Changes” in the top-right corner.

Step 2: Move the Executables to PoE 2

  • In the Profiles bar, search for “Path of Exile 2”.
  • Click “Add Application” button.
  • Navigate to your PoE 2 game folder inside Steam.
  • Add “pathofexile_x64steam.exe” and “pathofexilesteam.exe” here.
  • Click “Apply Changes” to save.
