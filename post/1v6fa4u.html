Mariners fan and college student here: I built “Wheres That Baseball”, a FOSS tool that tracks live game play, every hit/pitch, and other stats in high detail

Spent the month or so working on a site called wtbb.org (Where’s That Baseball).

Note: this isn’t meant to replace gameday/fangraphs/bref/savant. However, I’ve learned a lot regarding how the mlb/statcast api works, and wanted to create something that showcases a bit of visualization/statistics about each player/team in a way that’s intuitive and fun to use!

Right now you can interact with:

  • Interactive 3D arcs for hits across all 30 ballparks.
  • Real-time play by play, spray charts, and embedded video clips for all plays.
  • Live pitch locations overlaid against batter OPS by zone.
  • Tracking team/player metrics (LOB%, Nobletigers, #back2back homers, % runs scored with 2 outs, meatball whiff rate etc…) over time.

Completely free, ad-free, and open source (https://github.com/lightningbolts/wheres-that-baseball). I built it mostly for myself and friends, but figured people here might find it useful.

Check it out at wtbb.org, please let me know if you have any ideas for features to add or bugs to fix! (hopefully mods don’t take this down :(()
