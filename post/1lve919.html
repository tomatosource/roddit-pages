How would you design a new endgame?

Greetings fellow exiles. 0.3 is soon upon us and with it i see many comments regarding the endgame and the wish for a full rework of it.

Some people just want to port PoE1’s endgame into PoE2, but many other players want GGG to deliver a more unique experience to PoE2, while also make it as good as PoE1.

So, to these kind of players that really wish to see something new and great i wanted to create a fun discussion and brainstorm on alternative forms of endgame that you would design for PoE2 if you had the chance.

This is just meant to be a fun discussion, there is no right or wrong here, but feel free to discuss these ideas and try to refine them (in a respectful manner).

So to kick this off i will start with my own idea:

Currently i see 3 main complaints regarding current end game:

  1. Infinite map is not fun and removes a sense of goal in the endgame
  2. Having no control on which maps you run and having to run “unfun” maps to get to where you want
  3. Towers

So my proposal to try and fix those issues is something like this - What if instead if waystones you will find “maps” of uncharted territories. These maps are not like the maps of PoE1, but more like a treasure map which you open and see a layout of areas. These maps contains a cluster of instances (which are the “maps” we have now) connected to eachother in a chain. You start in the first instance and work your way to the last one, Which will always contain a boss. You can find maps with 2 or 3 instances for example, or even 6 or 7.

When running through a map you will see the chain of instances and before starting the next instance you could juice it and reroll its mods just like how its currently is with waystones.

The catch - juicing is carried over from instance to instance in the chain (yes, PoE1 players, i took this idea from the current league) So the longer the chain the more juiced you accumulate.

The maps will be placed on a special table which will let you enhance the map with Tablets and reconfigure the map in certain ways like change the type of instances or add other special modifiers like adding more instances.

And finally - there will be a “world” overview (lets say it looks kinda like the current endgame map) that will gradually unlock more and more areas when you complete your maps based on the types of maps you finish. Tbh i’m still not sure what to do with that part, but i wanted to have something to “complete” while you run maps. It could be used to unlock some endgame pinnacle content or get more deterministic maps but i’m not sure how.

Overall thats the type of endgame i tried to brew here. Hopefully it sounds good and not too convoluted 😅 Feel free to write down your ideas
