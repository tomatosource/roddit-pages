[Analysis] Who’s the worst player whose career highs would be the greatest single game performance?

TLDR: I analyzed player career highs based on Game Score to see how they stack up as single games. You can scroll around the spreadsheet here, or download it as a .csv file here.

A few weeks ago, u/ritmica posted a thread asking who is the worst player whose career highs have a claim on greatest single game of all time? Lots of interesting guesses in the thread - Scott Skiles, Brandon Jennings, Elfrid Payton, etc. My reaction to that was 1) these stats are pretty low considering some actual stat lines players have recorded; and 2) we can make some more informed guesses.

So to start off, how do we judge games (real and hypothetical) against each other? For this post, I’m going to use Game Score as a starting point. Game Score basically adds up all the positive things you can do and subtracts all the negative things you can do, with some weights. One of the advantages here is that I didn’t invent Game Score, so it’s tracked on Basketball Reference and other sites, and thus gives us a reasonable starting point for what the best games in history were.

To calculate each player’s career high Game Score, I started with this dataset of players and box scores, updated through the end of last season.

  • For certain counting stats, it’s generally easy to pull out highs - points, assists, steals, blocks.
  • For rebounds, Game Score weights ORB and DRB differently; I looked for the player’s TRB record and used the splits from the corresponding game. For games that don’t have ORB/DRB listed separately, I assigned all TRB to DRB for counting purposes.
  • Similarly, Game Score cares about shooting numbers, so I used the shooting numbers from the player’s career high points game. For really old games, we have FGM and FTM/FTA, but not FGA; I set FGA to 0 for those games.
  • Game Score also subtracts negative plays, namely PF and turnovers; I took the low of those, which for basically every player is 0.

The assumptions for the older games will skew things a bit, so stats for the older players will take a grain of salt. These assumptions generally cut in opposite directions (only DRB hurts, no FG misses helps, no steals/blocks hurts, etc), but worth keeping in mind. Not having any negative plays (no turnovers, no fouls) also boosts scores quite a bit.

We’ve gotten a little numb to great performances lately, but seriously - the NBA has seen 60 point triple doubles, 70 and 80 point games, and so on. The highest Game Score on record is MJ (naturally) with a 69-18-6 game clocking in at 64.6, but let’s be serious - the best game in history was Wilt’s 100, which does not have an “official” Game Score since some stats were not recorded (ORB/DRB, steals, blocks, turnovers). Using the assumptions above, Wilt’s 100 game gets a 76.8 Game Score. Given that bar, I was a little worried that the answer to even beat out MJ’s game was going to be like…Reggie Miller or some other Hall of Famer, but I was pleasantly surprised. Using the standard Game Score weights there are 87 players with career highs that beat out MJ’s game (only 13 players beat out Wilt’s 100 game, so…pretty high bar).

From there, the second half of the question is who’s the worst player on the list, which is something of a judgement call. You can browse around the spreadsheet yourself and pick out your favorite person to start a fight about. I’d put forth someone like Purvis Short (59-15-14-6-3, no All Star appearances) or Dana Barros (50-13-19-7-2 on only 26 shots, 1 All Star appearance but just shy of 9000 career points).

In general, these stat lines tend to be those with high points scored. The biggest contributor to Game Score is points, which is fair enough - that’s what counts in the end. But for this exercise, the guesses in the previous thread (and my personal feeling) is that it’s more fun to see a line with higher stats across the spread versus one with lots of points and like 5 rebounds. So let’s tweak the weights so that rebounds and assists are weighted the same as points. This bumps up the target scores as well (MJ’s game goes to 76.2, Wilt’s game goes to 94.9), but still opens up the aperture. With the adjusted Game Score*, we’ve now got 155 players who beat MJ and 15 who beat Wilt. Some of the players mentioned in the thread show up here: Scott Skiles and Brandon Jennings are in there, Jusuf Nurkic sneaks in, etc.

Again, up to your judgement who the worst player is, but a couple of fun stat lines:

  • Elmore Smith - 40-26-8-5-17 blocks
  • Nick Anderson finally takes out MJ - 50-15-12-8-4
  • Andre Miller bolsters his case as best player to never make All Star - 52-12-22-9-3
  • Larry/Muhsin Kenon - 51-21-11-11 steals-3

I can think of some different ways to rate games (one idea was to look for how close guys came to the single game record), or how to rank players, but I’ll save that for a followup if I have time. Have fun scrolling around and Remembering Some Guys!
