Smith of Kitava bad nodes of Smith’s masterwork - are they really bad?

As a chieftain enjoyer, I was really impressed with the new Smith of Kitava ascendancy. However, from a first glance it seems like there are few good nodes and some really bad nodes. So why would GGG put “bad” nodes on purpose. I think that based on this we can assume the following division:

Currently mediocare nodes: Crit reduction, armor against chaos

Overall good nodes:

  1. 25% phys as fire

  2. 15% maximum life

  3. 5% life regen

  4. 75 fire res

  5. 5% max fire res

Build defining nodes:

  1. Unaffected by ignite - self ignite build

  2. 20% str - str stacker (lots of empty suffix for str)

  3. Stun threshold - for active block/parry, something like magma barrier

  4. Cold/lightning res (explained below)

So why does cold/lightning res are build defining nodes. This is the same answer as for the unaffected by ignite. At the moment, it’s certainty not. However, since these are clearly not worth it now, this suggests to me that there are new passives/uniques that are specifically for those. Self ignite is a real thing in POE 1 and I believe we are getting a unique for that (maybe something like fulcrum?). Regarding cold/lightning res, since we already have uncapped res node on the tree (Unnatural resilience), we might get additional ones for cold and lightning. In addition, uniques for overcapped resistance might be added.

Think about this cool scenario. There is a damage node for overcapped lightning res. We will take the lightning res node on the ascendancy tree but now we have a real tradeoff between adding more fire res and be more tanky (with Unnatural resilience) or add more lightning res (topaz vs. ruby rings) to get more damage.

It’s mainly guessing but I think this might be the case here. What do you think?
