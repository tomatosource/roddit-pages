Build diversity

To start i must say that 0.4 was really good for build diversity compared to other leagues and it’s been a blast so far but I do have a bit of a gripe that I can’t seem to understand the reasoning for.

Why do we need to have set starting locations on the passive tree?

I get the want/need for class being a determining factor but if the ascendancy is good enough people will play from any part of the tree.

someone told me that it should be a central starting point and while I don’t hate the idea I think how we have it now is fine but let us be able to choose where we start on the tree then lock that point(so we can’t start at 2 different points) this would increase build diversity by a ton without making the tree feel so much like a limitation.

a warrior hollow palm, minion tactician, hammer witch, spellslinging witch hunter would all be soo cool to build but they are so far from key nodes that it lowers any incentives for even attempting it if you’re not bored out of your mind.

let the ascendancies breath and give us the agency to be as creative as we possibly can be the weapon already locks lots of doors so having redundant limits is pointless.

ps. pf would still be able to have 2 different starting positions without problem.

tldr: let us choose our own starting positions on the passive tree to have better build diversity.
