For my fellow Linux enjoiyers: Path of Building FYI

Hello to all my Linux friends! I’m playing on the current version of Bazzite and it runs great with Vulkan. Just as an FYI for anyone wondering: if you add the Path of Building tool as an .exe game in Steam, you can launch it normally with Proton without any issues. I had a few problems getting it to run at first, so I wanted to share this information.
