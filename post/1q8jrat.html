Having to fit rarity on gear is the most frustrating part of creating a build in POE2

We all know that there is a light and day difference in this game if you play with or without rarity. And that is really build limiting or strategy limiting.

I was trying to put together a build that requires several uniques and then I need to figure resists with 3 rare items (one of them being boots which doesn’t have rarity as prefix), I’d need triple res on all of them including Chaos. Even if I were to invest heavily into rings with lots of resists, decent prefix + rarity, I’d still have very little rarity to be able to get decent enough loot.

So unless I’m willing to ONLY farm ritual, citadel fragments or flipping, I would need a build with high rarity invested. Meaning this build is invalid because it won’t be able to farm properly other content.

Can we please have rarity from gear removed from the game from next league onwards? Or else new and interesting builds will be only for show.
