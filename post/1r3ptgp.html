Waystone and tablet rework idea

I find mapping to be pretty tedious. There’s lots of issues with it, one being that it feels a little aimless. I don’t have any suggestions for that, I hope ggg has some ideas to spruce that up.

My other issue is with slamming orbs into waystones and tablets to get them prepped to run a map. Sometimes I feel I spend more time doing that than actually running a map. When I sit to play, the thought of doing the setup makes my eyes roll over. I know it’s been massively improved since 0.3, but there’s still a lot of room for improvement.

My thought (and it’s not very flushed out) is that when I go to the map device, I should be able to select what level waystone I want from there (1-16), and then I just select how many mods I want on it (and the currency is just deducted from my stash, instead of me slamming it in), and the same way I can select what I want on my tablets. So I select 1 abyss, 1 breach, 1 irridiated, and the more mods I select on it, the more currency it costs. It shouldn’t be totally deterministic, it should be a pool of mods that can roll on the tablets and waystones. You could add some determinism to this by letting u use your Omen (of rarity, of pack size etc) if u have it in ur stash. They could make some versions of these for tablets too.

Just basically, let me interact with the map device and select what all I want, and the game go head and deduct all the needed currency and let me just go blast.

I know there is a “rework” of the endgame coming in 0.5, so who knows what this interaction is, but I really hope they streamline some of this even more. It’s too much setup.
