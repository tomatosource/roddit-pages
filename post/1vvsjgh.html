Speed Run tool 3.0

Hello again everyone,

I’ve been making slow and steady progress on my speed running tool for PoE2. Since my last post, I’ve made significant updates and fixes to the setup program. Major points includes:

  • Fixed boss watcher logic - now properly references the user’s screen resolution so it properly dissects dual boss encounters.

  • Fixed Sekhemas and Chaos trial runs

  • Added logic for Maps and Pinnacle bosses

  • Added multi-language support for all the PoE2 supported languages: {English, French, German, Spanish (Spain), Japanese, Korean, Portuguese (Brazil), Russian, Thai}. (Feedback on the UI translated text would be appreciated since AI was used and I can’t afford to hire proper translators.)

  • Also included translated versions of the README file into those languages. (feedback on the translations would be welcome as AI was used.)

  • SHA256 Checksums: These are sequentially generated SHA256 checksum values that are automatically generated at different points of a speedrun. They can be validated with the built in tool to prove the file has not been altered after generation. It is not meant to replace video recorded verification, but rather compliment it.

  • Next Planned major feature: Vaal Temple

Huge shout out to u/Designer_Throat_8125 for their help in play testing some of the features and providing some bug reports.
