Struggling to stick to one build, this game has so many options and I want to try them all.

Is anyone else like this? I love games that allow so many different ways to play and this game has really taken over my life recently. Problem is, I’ve barely progressed in the end game because I just keep wanting to try everything! Here has been my league so far:

  1. fire spells look cool so I started as a sorc for this, but soon realised I didn’t like damage over time and wanted heavier hits
  2. So I went to warrior, loved it, finished the campaign, but I saw how cool the ice monk looks and plays so changed to a monk to try that
  3. Monk got to act 4, it was great being so fast and having the ability to freeze everything, but then I craved range
  4. So went back to my sorc and respecced into an ice/lightning build, easily one of my fav ways to play so far
  5. But then I realised other classes like the ranger have Ice arrows, so I tried that and it’s by far the most fun I’ve had this league

And of course, this has wasted a lot of progress that I could have just done on one character in the end game. Still having fun, just wondered if others have this issue!
