PoE 2 Sound Device reverting to default

So there are multiple threads on this already but none of them resolve the issue.

My issue is that every time I start the game the sound device for the game has reset to the default system device. I am currently using the WaveLink software to route my audio to different channels and I have a specific channel for games which has a separate slider for volume.

Potential solutions I have tried so far:

Start the game

Go to options

Set the output audio device to the correct device (in my case Wave Link Game)

Save options

Switch to Windows desktop

Go to Sound Settings (right-click on speaker icon in taskbar)

Check my default output is correct

Go into “App volume and device preferences”

Check default device (again) is correct

Scroll down to Path of Exile 2

Set output device (top drop-down box) to Wave Link Game)

Quit / Restart the game

I have tried this multiple times, without closing the game and closing the game while doing this doesn’t matter.

I have also tried various suggested solutions in relation to OneDrive, most notably this one:

Open File Explorer.

Go to your “Documents” directory.

Locate and right-click on your “My Games” folder.

Ensure the option “Always keep on this device” is checked in the context menu.

Finally, double check that the “My Games” folder (and sub-folders) are now stored locally on your PC (indicated by a green check mark within a green circle to the right of the folder/file’s name).

go to \Documents\My Games\ find Path of Exile 2, right click it, pick properties and make it not hidden.
