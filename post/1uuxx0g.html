Game-breaking bugs currently trending (Weapon-swap & Jewel Socket)

Game-breaking bugs are currently trending in the community. Although we are at the middle of the PoE 2 0.5.0 season, I am sharing this here in hopes that GGG will notice and fix them.

The following is a translation of a post that was uploaded to a Korean community (DC Inside Path of Exile 2 Gallery).

These are bugs that have been floating around the Chinese community for the past couple of days. Since I’m taking a break for the rest of the season, I decided to share them here.

Bug 1 : The Weapon Swap Skill Exploit (Cross-using skills)

Let’s say Weapon Set I is your main weapon. You can actually use skills granted by the weapons in Weapon Set II while holding Weapon Set I.

How it works:

  1. You need to force Weapon Set II into a “disabled” (red background) state by using an item restriction limit shared with Weapon Set I.
  2. For example: Socket an Idol/Augment with a “Limited to: 1” tag into both Weapon Set I and Weapon Set II.
  3. Because you can only have one, when you swap to Weapon Set I, Weapon Set II will turn red (disabled).
  4. The Exploit: Even though Set II is disabled, you can now put the skills granted by Set II onto your skill bar and use them while holding Set I.

https://preview.redd.it/yiy5fr3yiwch1.png?width=226&format=png&auto=webp&s=755454c3ad985f6ce45e144e4c7e795342c6a9f5

(See the first screenshot for an example). By doing this with the unique wand Adonia’s Ego in Weapon Set II, you can cast Pinnacle of Power while actively holding a Bow in Weapon Set I.

According to the Chinese community, theoretically, this means you can do things like wielding 4 Mjolners at once.
(Note from the comments: This doesn’t seem to work in town. You have to enter a map/instance for the skills to become active on your skill bar).

Bug 2 : “From Nothing” Jewel Socket Saver

This second one isn’t a huge deal and is actually quite old. It’s not very practical, but I was debating whether to write it or not, so here it is.

How it works:

  1. Socket the From Nothing unique jewel (Passives in Radius can be Allocated without being connected).
  2. Allocate the disconnected nodes you want using Weapon Set I.
  3. For the attribute/travel nodes on the path to that cluster, allocate them using Weapon Set II.
  4. Because of how the game registers the different weapon sets allocating the nodes, you can actually un-socket the From Nothing jewel, keep the disconnected nodes active, and get your jewel socket back.

https://preview.redd.it/exwzt9oziwch1.png?width=783&format=png&auto=webp&s=925da5284a97a6d74acf0a33e9ad76828a5b21ed

(See the second screenshot). It’s a bit hard to explain in pure text, but it looks something like the image. You use different weapon sets to allocate the attribute nodes vs the main cluster, allowing you to pop the jewel out.

The Catch: The moment you relog or disconnect, all those unlinked nodes will be automatically refunded. So, this exploit is only for people willing to endure the annoyance of re-doing their tree every single time they log in.
