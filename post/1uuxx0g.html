Bug 1 : The Weapon Swap Skill Exploit (Cross-using skills)

Let’s say Weapon Set I is your main weapon. You can actually use skills granted by the weapons in Weapon Set II while holding Weapon Set I.

How it works:

  1. You need to force Weapon Set II into a “disabled” (red background) state by using an item restriction limit shared with Weapon Set I.
  2. For example: Socket an Idol/Augment with a “Limited to: 1” tag into both Weapon Set I and Weapon Set II.
  3. Because you can only have one, when you swap to Weapon Set I, Weapon Set II will turn red (disabled).
  4. The Exploit: Even though Set II is disabled, you can now put the skills granted by Set II onto your skill bar and use them while holding Set I.

https://preview.redd.it/yiy5fr3yiwch1.png?width=226&format=png&auto=webp&s=755454c3ad985f6ce45e144e4c7e795342c6a9f5

(See the first screenshot for an example). By doing this with the unique wand Adonia’s Ego in Weapon Set II, you can cast Pinnacle of Power while actively holding a Bow in Weapon Set I.

According to the Chinese community, theoretically, this means you can do things like wielding 4 Mjolners at once.
(Note from the comments: This doesn’t seem to work in town. You have to enter a map/instance for the skills to become active on your skill bar).

Bug 2 : “From Nothing” Jewel Socket Saver

This second one isn’t a huge deal and is actually quite old. It’s not very practical, but I was debating whether to write it or not, so here it is.

How it works:

  1. Socket the From Nothing unique jewel (Passives in Radius can be Allocated without being connected).
  2. Allocate the disconnected nodes you want using Weapon Set I.
  3. For the attribute/travel nodes on the path to that cluster, allocate them using Weapon Set II.
  4. Because of how the game registers the different weapon sets allocating the nodes, you can actually un-socket the From Nothing jewel, keep the disconnected nodes active, and get your jewel socket back.

https://preview.redd.it/exwzt9oziwch1.png?width=783&format=png&auto=webp&s=925da5284a97a6d74acf0a33e9ad76828a5b21ed

(See the second screenshot). It’s a bit hard to explain in pure text, but it looks something like the image. You use different weapon sets to allocate the attribute nodes vs the main cluster, allowing you to pop the jewel out.

The Catch: The moment you relog or disconnect, all those unlinked nodes will be automatically refunded. So, this exploit is only for people willing to endure the annoyance of re-doing their tree every single time they log in.

Enjoy your PoE!

UPDATE: Advanced Applications of the Weapon-Swap Exploit

(Disclaimer: The following information is translated from a Korean YouTube video, so please excuse any inaccuracies in the translation!)

A Korean YouTuber recently uploaded a video showing that this weapon-swap bug is much more game-breaking than initially thought. Currently, the community is growing increasingly frustrated; players who want to play standard builds feel heavily disadvantaged, and there is a negative sentiment forming around feeling “forced” to use this exploit just to compete.

While most players are only focusing on getting the Pinnacle of Power buff from Adonia’s Ego, the core of this exploit allows for massive abuse of game mechanics in two major ways:

1. Sceptre Aura & Absolute Immunity Stacking (via Guild Stash Bypass)
You can apply this bug to Sceptres in both Set 1 and Set 2 to double-dip on Spirit reservations and aura buffs. If the game’s UI prevents you from equipping the restricted items/runes on both weapon sets to break them, you can bypass this using the Guild Stash (socket Set 2 -&gt; put in Guild Stash -&gt; equip Set 1 -&gt; retrieve and equip Set 2).

  • The Setup: The YouTuber demonstrated using two different Shrine Sceptres. For example, Set 1 has Sacred Flame (Grants Purity of Fire), and Set 2 has Guiding Palm of the Eye (Grants Purity of Ice).
  • The Support Gems: They socketed three persistent buff support gems into BOTH Sceptres: Cool Headed, Strong Hearted, and Warm Blooded.
  • The Result: Because the bug allows both weapon sets to function simultaneously, the 50% ailment avoidance from the gems in Set 1 stacks with the 50% from Set 2. This grants 100% absolute immunity to Freeze, Shock, and Ignite. Furthermore, you get both massive Sceptre Shrine aura effects (Purity of Fire and Purity of Ice) at the same time, completely trivializing elemental resistances with zero effort

2. Stat-Sticking Unique Skills with High-DPS Weapons
Many unique weapons have incredible granted skills but are balanced by having low base DPS or awkward tags. This exploit completely removes that downside by letting you cast the unique skill using the stats of a top-tier rare weapon equipped in Set 1.

  • The Unborn Lich (Staff): Disable this in Set 2. Equip a massive high-DPS rare staff in Set 1. You can now cast Feast of Flesh utilizing the massive damage of your rare staff, resulting in absurd DPS.
  • Roost of the Raven King (Staff): This staff usually lacks DPS because of its minion tags. Disable it in Set 2, equip a top-tier spell damage Sceptre/Staff in Set 1, and you can cast a vastly overpowered Spiraling Conspiracy.
  • Mjölner (Club): You can disable two Mjölners in Set 2, and dual-wield two other Mjölners (or high DPS maces) in Set 1. This effectively gives you 4x Thundergod’s Wrath triggering simultaneously.
  • Brutus’ Lead Sprinkler (Mace): Disable in Set 2, equip a top-tier Mace in Set 1 to scale Molten Shower to extreme levels.
  • Spire of Ire (Spear): Disable in Set 2 to use Chaotic Surge with a much stronger spear.
  • Fairgraves’ Curse (Bow): Disable in Set 2, equip a top-tier physical bow in Set 1, and use Phantasmal Arrow with massive scaling.
  • The Last Lament (Crossbow): Disable in Set 2, equip a top-tier crossbow in Set 1, and fire Requiem with huge base damage.
  • Fury of the King (Talisman): Disable in Set 2, equip a highly rolled Talisman in Set 1, and use Molten Crash.

As the video points out, the applications are limitless, completely breaking the intended balance of unique items. We need a fix for this.
