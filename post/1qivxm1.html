[Guide] Fix Blink accidentally triggering Sprint / character stopping (AutoHotkey double-space fix)

If you’re using Blink and you’ve noticed that after blinking it sometimes triggers Sprint and makes your character stop, this simple AutoHotkey fix completely removes the accidental Sprint activation.

✅ What this does

It makes Spacebar always press twice (very fast), but ONLY while Path of Exile 2 is focused.
https://www.youtube.com/watch?v=08riEU076cg

So:

  • Blink works normally
  • Sprint doesn’t accidentally trigger and stop you
  • Alt+Tab out = script does nothing outside the game

Step 1: Install AutoHotkey (v1.1.37.02)

Download AutoHotkey v1.1.37.02 (not v2):

  • https://www.autohotkey.com/download/1.1/AutoHotkey_1.1.37.02.zip

Step 2: Create the script

  1. Right click Desktop → New → AutoHotkey Script
  2. Name it something like: poe2_blink_fix.ahk
  3. Right click it → Edit Script
  4. Paste this:

​

#NoEnv
#SingleInstance Force
SendMode Input

; Only while POE2 is the ACTIVE window
#IfWinActive, ahk_exe PathOfExileSteam.exe

$Space::
Send {Space}
Sleep 50
Send {Space}
return

#IfWinActive

; Optional: press F12 to close the script
F12::ExitApp
  1. Save and close.

Step 3: Run it

Double click the .ahk script to run it.

You’ll see a green H icon in your taskbar tray → that means it’s running.

✅ Step 4 (Optional): Auto-run when Windows starts

If you want this to always run automatically:

Method: Startup folder

  1. Press Win + R
  2. Type:shell:startup
  3. Press Enter (this opens the Windows Startup folder)
  4. Copy/paste your script poe2_blink_fix.ahk into that folder

It will now auto-run after reboot / login.

Important Notes

✅ Works only inside PoE2 (Steam): PathOfExileSteam.exe
✅ Does nothing outside the game
✅ No toggle needed, always active only in-game
⚠️ If you use a different PoE2 exe (non-Steam), check Task Manager → Details for the correct name.
✅ You can just Ignore everything in this post and just press spacebar twice manually
