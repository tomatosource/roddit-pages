Ability to convert allocated skill points into weapon set skill points

I’ve been thinking alot about dual skill tree setups recently after the teaser that you can use the same weapon in both weapon slot 1 and 2. As it is, it’s quite cumbersome to have to remember to switch weapon sets before allocating your skills. That’s if you even know what weapon set you want the points to belong to when allocating them.

It’d be easier to be able to allocate all your nodes as usual, and then if you realize that e.g. the lightning pen nodes you took only benefit half the skills you ended up using, you could retroactively mark them as “weapon set 1 skill points” and free up an equal amount of weapon set 2 skill points. If you want to do that today you’d have to first pay to unspecc the points and then reallocate them. I think this would be a great QoL update.
