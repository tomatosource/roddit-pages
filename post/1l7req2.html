Idea: what if you could run multiple maps in one go?

https://preview.redd.it/90u6akosj16f1.png?width=1536&format=png&auto=webp&s=b7be703d870d468219bd42d678a66e38e7dfdcfa

Had a random thought — what if the atlas had some kind of feature that lets you chain a bunch of maps together in one session?

Like say you power up an area with 2-4 towers or altars or whatever, maybe add quantity/rarity buffs, and then when you open one map through a waypoint, it links all nearby maps too. you run through the first one, finish it, then just transition into the next without going back to your hideout.

The buffs from the waypoint (or towers) carry over across all the linked maps. so you’re basically doing a mini-gauntlet run through a region, with the same modifiers and higher stakes.

Feels like it could make atlas investment more interesting, and would be a good way to run longer farming sessions without the stop/start of hideout hopping.

Dunno if it’s too much or if it breaks balance, but just putting it out there. would you try something like that?
