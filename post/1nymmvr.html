Fix to abnormally long loading times between zones

THIS IS COMPLETELY RANDOM FIX THAT WORKED OUT FOR ME AND I DO NOT GUARANTEE THAT IT WILL WORK FOR ALL THEREFORE I AM NOT TAKING RESPONSIBILITY FOR CASES WHERE AND IF IT BRICKS SOMETHING FOR SOMEONE. DO IT ON YOUR OWN PRECAUTION IF YOU WILL!

  • Complaint: very long loading times upon things like accessing new zones or attempting to jump back to already active zones (for example getting back to the map from the abyss pit, revival or teleporting between checkpoints, returning back to the map after hideout flask refilling and other similar loading related scenarios)
  • Initial PC conditions: Standalone PoE2 client installed in the same m.2 drive as Windows 11, RTX 2070, i5 - 6 cores.
  • Previously made attempts in search for the fix: countless, failed
  • Fix that worked for me:
  1. moving whole installed PoE2 client folder to a separate drive (away from where Windows 11 is installed)
  2. changing the default client path of “%userprofile%/Documents/My Games/Path of Exile 2” via Command Prompt under administrator rights (to be located in the same separate drive where the client was moved to)

I believe there are different ways to do this but here is a sample of what I typed in the Command Prompt:

mklink /J “C:\Users\&lt;YourUser&gt;\AppData\Roaming\Path of Exile 2” “D:\&lt;New Folder&gt;”

Note: to make this work you have to rename the &lt;YourUser&gt; part of the code to whatever it is called on your PC and [important!] you must NOT forget to create destination folder (&lt;New Folder&gt; in the sample) exactly where the typed command dictates and it also has to be named exactly the same as in the command(you can name it whatever you like but the code part and the created folder name has to match). If everything is done correctly - you should be seeing an automatically created “Path of Exile 2 Shortcut” in the initial folder path and the newly created folder will be gradually populated by the game files upon logging to the game via “PathOfExile_x64.exe”. When opening loot filter folder trough the game settings - it should open it in the new location you made game to link to.
