Recombination is a missed opportunity

So I don’t want this to seem like too much of a rant but I’m super annoyed with trying to make recombination work …

So first just let me say I get that it’s for a very niche case but when something is so niche and so limited it almost shouldn’t exist at all.

Recombination could have made finding any T1 modifiers really exciting. Knowing that you might be able to assemble your own base to start crafting is such a cool idea. Sadly the percentages are so tiny that 1) it can only be used in trade league, it might as well not exist in SSF, and 2) it doesn’t add any excitement to raw drops thar fall for you.

Like I said at the start, I’m fine if this is just a niche tool for super end game crafting but it just feels like a missed opportunity for a fun and exciting gameplay mechanic.
