2.1 Lag/Stuttering Fix

If you’re having cpu spikes, lagging/stuttering, it’s likely chat. Here’s the main 3 compiled fixes you can try until GGG fixes the underlying issue.

*Delete client.txt from folder logs. Located in main PoE2 folder.

*Options &gt; Interface &gt; Chat &gt; Turn off output dialogue to chat

*In chat type:

/clear

/global XXXXX

/trade XXXXX

XXXXX = any 5 random numbers Repeat above if it starts lagging again.

We’ve had several threads with the fix but I keep seeing new threads with the same issue pop up. Not blaming anyone, just wanted to make a dedicated post for it. If the mods could please pin the information or something until GGG fixes it, that’d be great too.

If anyone found other solutions, please share.
