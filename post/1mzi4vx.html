Suggestion for towers 0.4

Just thought from a new player perspective.

I like the idea of the explorable map but the tower generation is way too random giving the players fomo wanting to only run 3 overlapping towers. We all can agree that.

What if we remove the tower generation in the map randomly but players can find a construction beacon. This can allow the players to pop the beacon with the waystone allowing the player to run the map with a tower mechanics and in return constructing the tower.

Now to juice. The beacons can be found in 3 different rarities

Regular tower beacon, greater tower beacon and perfect tower beacon. All have various radiuses but affect the map the same way so there will be no fomo to not run the maps.

Additionally they also affect how far you can see in the atlas map screen removing fog of war.

This gives player choice to generate their own towers.

Now to overlapping mechanism. We can have this or not.

One solution is only to have one tower in the radius. I would like the towers to be included in atlas screen. But that would mean the next path you take you have to run multiple maps without juice.

The second solution is allowing players to only plop them in maps which can allow tower construction. They can have a special icon in the overall pool which can be controlled like 1 in 15 maps can be converted to tower. For eg.

With different variety of tower beacons this can create variety of tower areas with different radiuses Or maybe add unique tower beacons.

What do you guys think?
