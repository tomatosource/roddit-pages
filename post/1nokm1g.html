PoE2 Trade page assistant - Alpha

Hey all!

I’ve been working on an open-source Chrome extension that assists in item searching on the PoE2 trade site. It is in alpha stage, but functional - so looking for feedback and people to help test it out.

Links

GitHub here: POESearcher
Download links/releases here: Releases

How it works:

You copy the item in came (Ctrl + C) on item and pasting it into the trade assistant and it populates the stat filters to try and find similar items to help with pricing your items for sale

https://i.redd.it/mhldwxvxnxqf1.gif

There are some installation instructions on the github page. I aim to get it on the Chrome Extension webstore if there’s enough uptake.

If this is in any way a breach of GGG TOS, please let me know, but there is no mal-intent, just trying to speed up my efficiency pricing items.

All the best :)
