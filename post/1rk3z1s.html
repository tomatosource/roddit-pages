Temple Energy - A case study

Hey all,

I wondered for a while what causes the vaal temple on maps to give you more or less energy. So I decided to make a study while farming and see what the outcome is.

I ran normal maps without any events like bosses, corruption, cleansed or similar. I usually ignored random content, unless I was forced to do it (e.g. abyss on linear maps). I also did not chose any specific map types at all. I finished all maps to get some waystones and/or to reveal the vall temple. So much about the general setup.

I ran the following maps (waystone level / corrupted=yes or no / tablets= yes or no / number of waystone mods / number of runs &gt;&gt; average energy per run).

T14 / Corr=Yes / Tablets=no / 6 Mods / 48 Runs &gt;2.00 Energy/run

T15 / Corr=No / Tablets=no / 6 Mods / 48 Runs &gt;&gt;2.02 energy/run

T15 / Corr=Yes / Tablets=no / 6-7 Mods / 48 Runs &gt;&gt;2.04 energy/run

T15 / Corr=Yes / Tablets=yes* / 6-7 Mods / 48 Runs &gt;&gt;2.04 energy/run

(* I used 3 precurser tablets without waystone drop chance modifier, so maps were irradiated)

T15 / Corr=Yes / Tablets=yes** / 6 Mods / 24 Runs &gt;&gt;2.04 energy/run

(**for this run I used waystones with high waystone drop chance of 100+% and tablets with waystone drop chance modifiers)

T15*** / Corr=No / Tablets=no / 6 Mods / 12 Runs &gt;&gt;2.08 energy/run

(***These tablets were modified with omen of chaotic quantity, giving them a high pack size)

T15 / Corr=Yes / Tablets=no / 8 Mods / 48 Runs &gt;&gt;2.54 energy/run

T16 / Corr=Yes / Tablets=no / 6 Mods / 48 Runs &gt;&gt;2.25 energy/run

Unfortunately, the data is not clear for the T15 Corrupted maps, as I did not realize that I had some 7mod maps in there. I might make another run with 7mod maps specifically, just to see where I end up with…

We can conclude the following from the data:

  1. It makes no difference, if you run corrupted, T14, uncorrupted T15, or corrupted T15 with 6 mods. You basically get 2 energy/map.

  2. It makes no difference if you use tablets or not (at least irradiated tablets, but there is no reason to believe that other tablets might have a different effect)

  3. Waystone drop chance has no effect on energy gained.

  4. Pack size has no effect on energy gained.

  5. If you run T16 maps, you will get more energy per run, which is about 2.25.

  6. While T16 maps give you increased energy per map, irradiated corrupted T15 maps do not give additional energy. It seems like monster level has no influence on energy.

  7. The most energy is gained while running T15 8 mod maps, with about 2.54 Energy gained per map.

While the difference does not seem to be a lot, it is quite noable… T16 Maps give you 12,5% more efficiency, 8mod maps about 25%.

So if you want to get the most energy per map, you use Corrupted T15 8 mod maps without tablets (tablets dont hurt your energy, but they might slow you down…).

Do you have any other parameters you would like to have checked? If I find some time, I could do some more data points.

See ya runnin’!
