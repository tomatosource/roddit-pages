Druid passives are likely to be alt passives, not default

I was planning to start with the Sorceress, and path to the Druid nodes, when a though struck me…what if they aren’t there?

Example: If I start out as Druid, the northern passives are set to the Sorceress, no minion nodes are available, they only appear if you choose the Witch.

Down at the Huntress/Ranger area the default is Ranger, with the Huntress nodes only being available if you select that class.

So, if you are planning on starting a non-druid class, and pathing over to the Druid area, these *most likely* are going to not be the Druid nodes.

Might be something to take into account if you’re planning a passive tree out now
