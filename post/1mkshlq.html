Dawn of the Hunt Price Log Dataset - POE2 Scout

Hey everyone! Just like last league, I’ve released all the price logs that my site (POE2 Scout) has collected through the latest league. The dataset covers both Standard and Hardcore leagues, with prices normalized to exalt values. The data format is slightly different this time around due to a complete redesign of the site before 0.2.0. Format will be more consistent going forward.

You can grab the dataset and check out the documentation here: Caidora/Poe2ItemPriceDump.

Going forward, I wasn’t happy with the usefulness of the data collected this league. I’ve identified the areas where my logic needs to be improved, and I hope to see more stable pricing data next league.

To give some insight, the issue stemmed from using Exalted Orbs as the base value for all items. When the value of Exalted Orbs plummeted and they were no longer a primary trading currency, the values my site assigned to items in Exalts became very erratic (and so followed any item that was priced by my backend in exalts).

My plan is to introduce Chaos Orbs as a tracked currency. I will also make changes that will allow the system to automatically adjust to whichever currency is most commonly used for trading at the time on a per item basis.
