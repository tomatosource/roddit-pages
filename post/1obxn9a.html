Ascendancy skills should have the option to be locked to a weapon set

I don’t get why it isn’t that way already. They should have the option to restrict it to a specific weapon set like all our skill gems.

Right now you have to manually swap or use another skill that was set locked first and then use it, which can be very difficult in the heat of combat.

Apart from the fact that it just gives us more control over our skills various ascendancy skills can benefit from weapon set specialization. For example as an Invoker in my set 2 I can allocate a bunch of recharge rate passives and use meditate in that set to recover my es way faster.
