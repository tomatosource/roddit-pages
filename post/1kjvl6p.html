I’m a bit confused on how command skills and in particular Ice Bomb for the Skeletal Mage works.

When I look at the details for the skill Ice Bomb there’s a cast time of of 0.86s with several minions nodes in cast speed. However, the use time of the command skill is 1.25s. From the wiki I get the following:

“Increased cast speed lowers the use time (duration) that it takes to issue commands”

Since the use time doesn’t change with a socketed Arcane Tempo I assume that the use time only scales with player cast speed.

So there are a few questions here:

  1. Is use time just cast time? What is the difference? Why would you name it differently if it is the same?
  2. Does use time indeed only scale with player cast speed?
  3. Which cast time is used? Can I cast that skill every 0.86s or every 1.25s?
  4. Is a lower cast time on Ice Bomb completely irrelevant if the use time on the command skill is higher?
  5. What would happen if my use time on command is significantly lower than the cast time on Ice Bomb?
  6. If point 3 or 4 is true, doesn’t that make minion builds a lot weaker? Since you have to invest in both cast speed and minion cast speed.

This is an incredibly confusing skill, and could all be cleared up by just setting the use time on command the same as the cast time on ice bomb, have it scaled with minion cast speed (which makes the most sense) and remove the detail tab for ‘Command’.
