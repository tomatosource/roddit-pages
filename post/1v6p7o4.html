Massive Memory Leak / Shader Loop (31GB/32GB RAM usage in 1 minute) - Ongoing for 1.5 years, still not fixed?

Hi everyone,

I am writing this out of pure frustration because this memory leak issue has been happening since early tests/betas for over a year and a half now, and it makes the game completely unplayable for me.

Every time I open Path of Exile 2, within literally 1 minute of gameplay, my system RAM usage jumps straight to 31 GB out of my 32 GB total.

Here is what is happening and what I’ve investigated so far:

  • The Shader Loop: My local PoE2 shader folder is only around 231 MB, but my Nvidia shader cache balloons massively. Even after doing a completely clean wipe of my Nvidia shaders, the moment I boot the game, it goes into an infinite compilation loop.
  • RAM Stacking: Instead of compiling shaders, saving them to the SSD, and releasing the memory, the game engine locks all these assets directly into the active system RAM until the PC chokes.

I have already tried changing APIs (Dx12/Vulkan), running as Admin, toggling Borderless/Fullscreen, and adjusting Pagefile settings. Nothing stops this leak.

It makes no logical sense that a memory optimization issue this severe has persisted for 1.5 years into the game’s life.

Is anyone else still suffering from this specific Nvidia shader/RAM loop? GGG, please, we need an actual engine fix for this memory management.
