The only way to get better performance

Is to simply upgrade your CPU if you haven’t. (Specifically to x3d series), given how cpu throttled this game is.

I tried everything - rebar, shader cache, graphics settings, sound settings, lossless scaling, changing monitors, diff resolutions, fresh install, latest drivers, you name it I tried it, but I never extracted sustained fps increases and performance always dropped after extended sessions.

I did some benchmarking with cinebench and geekbench, and my new cpu (5700x3d) did not deliver huge gains both on single and multi core workloads against my old 3600 (15-20% gains). So I wasn’t expecting very large gains in game, tbh.

Gaming test (fry your pcbuild frostbolt infernalist, COC comet COA nova firebolt)

  • Ryzen 5 3600 + 3070, 3440p x 1440p at DLSS performance

60-70 fps (normal map) 30-40fps (juiced) 15-30fps (juice with party/abyss) 30fps ardura Caravan Hideout (60-70fps) Gpu utilization ~ 30-50% CPU temps 70-80

  • Ryzen 5 5700x3d + 3070, same resolution but DLSS quality

90-110 (normal map) 75- 100 (juiced) 70-90 (juice with party) 40-50 (abyss) 80 (ardura) 120 (hideout) Gpu utilization ~ 95-99% CPU temps 55-65

You might ask me, why the 5700x3d? Why not 7800x3d or 9000 series? I just needed a good value upgrade on AM4 and I somehow got a tray set for $100. I still figure my GPU can hold up till 6000 series.

TLDR: if you’re not running x3d chips from AMD, and you play lots of POE2, maybe it’s time to get one if you’re facing performance issues on an older system and if you can find a good deal. And, you don’t need to get the latest x3d, 5700x3d/5800x3d still punches way above their weight and are more than enough considering you have a decent GPU.

Extra tip: enable XMP in bios to fully access your top RAM speed!! I only recently found out about this it gives maybe like 2-5% gains
