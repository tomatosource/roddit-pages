250%-300% IIR, and I get nothing in return

Small rant.

Starting to question why going to extremes to stack rarity is worth it. I’m running anywhere from 250-300% rarity every single map with 20-30% quant, and I’m getting a “tink” every 10 or so maps. I understand “tinks” aren’t everything, I’ll get the occasional greater chaos orb or annul, but the “reward” for farming in this game doesn’t exist. In Poe1, when you farm/have proper juiced gear, you can start running staacked alva/blight etc, and you’re sufficiently rewarded, nothing like that exists in Poe2 (yet).

Rarity obviously is a luxury in this game. You never want to sacrifice defences or dps for it. When you “farm” enough where you can start to afford a rarity mod on an item, as well as the defence/offence mods you desire, you should be adequately rewarded. You aren’t.

I have176% base rarity, and I only run maps with 120%+ rarity. I alternate between greed/paranoia deli and rarity/quant tabs. Doesn’t matter, they’re all equally worthless.

I have zero interest in crafting. I know it’s way more profitable (as it is in Poe1 too), but I want to run maps to farm currency.

Understandably this is still beta, I hope this is fixed when the game is in full release.
