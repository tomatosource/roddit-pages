How do I use weapon swaps? + some ranting about this system

In preparation to play some PoE2 on Friday (I swear I will kill all pinnacle bosses this time and won’t just quit lvl 92-93ish when I fall off) this seems to be as good time as any to ask some questions that the game makes poor job of explaining and encouraging.

So, weapon swaps. What do I do with them? Last league I was running Witchhunter and I thought to myself - ok, so I can assign skills to weapon loadouts, so I probably should have some “shoot grenades with me” crossbow and “shoot other stuff with me” crossbow. On top of that, I can see that there’s a pool of passive skill tree points that I can reassign between weapon sets (so I am specced slightly different when I swap).

On top of that the Witchhunter ascendancy itself has a node that says this pool of interchangeable skills is set to 100 instead of 10 or 20, basically allowing you to be specialized in totally different skills, which I thought is a really cool thing. I know that Witchhunter is there since 0.1 but I only created 2 characters in total (spark elementalist in 0.1, skipped 0.2 after not being able to beat the campaign with the huntress).

I ended up not using these systems at all. First, when I was going through campaign, there was a bug that made my crossbows jam when using this option. They stopped reloading unless I clicked skills in some certain order, so that was garbage and I shot a single crossbow the entire game even if on paper that was suboptimal.

Secondly, because I never returned to the 1st system, I didn’t bother to interact with the passive tree swaps. Just ran some random build from a website I respecced to when I began mapping. Reassigning and branching out to slightly different passives when I (remember to) swap to another weapon felt like too much tedium - all the clicking, thinking that I would need to basically manage 2 builds, respeccing one would sometimes require changing the other, etc, looking for upgrades to not 1 but 2 weapon slots. I wouldn’t do it with 20 points, let alone 100.

This system of the game feels like something that I should be made aware of as a player and taught early in the campaign in a tutorial, maybe to familiarise me with the concept of having a weapon for mobs and weapon/build more tailored towards bosses. Yet it feels like some PoE1 mechanic that is obvious to PoE1 players so the game doesn’t bother to tell me how to use it properly.

So, how do I use this feature properly? What is some simple example of a character that uses it? Is every character “better” if you use it? Can it be ignored? How it works with slottable gems in the passive tree?
