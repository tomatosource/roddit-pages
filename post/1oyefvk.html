0.4 Quality of Life requests

QoL suggestions for 0.4

With 0.40 around the corner, what are some easy QoL changes you hope could be implemented? Minor changes that wouldn’t affect balance/gameplay/art/etc. I had the same thread for 0.3, and GGG did implement a few of these suggestions (thanks GGG!), so here’s to hoping they implement a few more this time around.

  1. Improve contrast for mod tier text and lines. (GGG did this for the tier lettering - awesome! Could you also update the contrast on the left-hand-side “Prefix” and “Suffix” text?)

  2. Simulacrum and simulacrumbs auto-send to Delirium tab.

(Simulacrum and simulacrumbs (splinters) currently get sent to fragment affinity tabs. Why? There’s a space for these in the Delirium tab, so that’s where they should go.)

  1. Improve the weapon set color contrast in the passive tree.

  2. Improve visibility of objects within blast radius of expedition charges, and improve visibility of circular blast radius indicator. (Not sure if this happened in 0.3)

  3. Drop-at-end splinter mechanic for all splinters (for example, for delirium, including for emotional waystones)

  4. Apply distilled emotions the same way currency can be applied (with a right click)

  5. Have a customizable favorites tab in the currency exchange.

  6. Speed up the recombination animation.

  7. Show mod ilvl.

  8. Option to toggle off clickable keywords (helpful in expedition and simulacrum for example).

  9. Reduce overlap between stash/portal/initiation window in simulacrum (the stash especially is often hidden).

  10. Icon indicating which weapon set is currently active.

  11. Add minimap icons for mechanics (ritual, breach, etc) once the map is complete.

  12. Streamline reforging bench to a vendor window so multiple items can be reforged at once (as in PoE 1).

  13. Allow distilled emotion upgrades in the stash tab (as with PoE 1).

  14. Add a search bar in the ritual rewards window.

  15. Maybe a heavier lift, but delirium fog is still a pain point for many (all?) players, especially in distilled maps.

Things GGG implemented from this list in 0.3:

  1. Improve contrast for mod tier text and lines. (Partial)

  2. Ctrl + click to send a currency from inventory to the Alva window.

  3. Fix symbol overlap in minimap (for example, when rare monster symbols and ritual symbols are both far away, only the ritual symbol will show, with the rare monster symbol being invisible). [obsolete for 0.3]

  4. Indicate suffixes and prefixes when holding alt (as is already done with the trade site).
