This fixed all of my performance issues! (Nvidia 3070)

Thank you to u/Tortorion who discovered this!

Him and I had performance issues, where FPS were slowly dropping from 144⁄160 to like 30⁄40 while playing and stay there until you restart the game, plus constant stuttering all over.

I tried everything reddit suggested, sound channels, shader cache, switching chat channels, raising shader cache limit etc.

But only after this my game went straigth to 160 fps and no stutters:

- uninstall current NVIDIA Drivers via DDU clean install

- get driver version 576.88 from NVIDIA website and install

- remove shader cache from POE2 folder

- ignore the message that pops up saying your driver is too old when starting the game

- First maps/instances always will be laggy, since shaders are rebuilding.
