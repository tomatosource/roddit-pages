We’ve updated the PoE2 web price checker today. I believe it’s worth trying it out if you don’t want to install third-party software on your PC, but still want to evaluate in-game prices fast

Hello Path of Exile 2 Community!

I’m the creator behind an online tool designed for checking item prices in PoE2 without needing any downloads or installations (the link at the end).

I was thrilled with the 0.3.0 update, where the developers began updating the trade mechanics to support asynchronous trading. That said, there’s still no integrated price evaluation feature in the game. In the meantime, while waiting for Grinding Gear Games to add one, I’m continuing to refine this simple utility that lets you search for comparable items using just the in-game item tooltip (hit Ctrl+C when hovering over something).

We’ve made some adjustments to align with the recent trade updates and improve usability:

  • Select which trade types to view (Instant, In-person, or a combination), mirroring options on the official trade platform.
  • View full search outcomes right on the site by scrolling - no more automatic redirects to the main PoE2 trade page.
  • Item visuals now render properly. It took some clever work with the trade API and content delivery networks to get this right, but now you can clearly see the items you’re evaluating.

https://preview.redd.it/jao88xryt3mf1.jpg?width=1034&format=pjpg&auto=webp&s=55405cd423c01e9ff0c96fd2258998cf1ed8f048

  • Included an easy way to report issues directly in the tool. With PoE2’s vast array of item possibilities, if something doesn’t look right, just use the report feature to flag it for me.

Where does this come in handy?

  1. When you pick up gear and aren’t sure of its value: Copy the tooltip (Ctrl+C in-game), input it into the site, and get instant matches. You’ll see pricing from similar listings, plus a detailed mod analysis where you can enable/disable stats, tweak ranges, and experiment with filters. There’s also a match precision slider - tighten it for exact results or relax it for broader ones.
  2. Spotting something interesting in another player’s base: Quickly assess if it’s a fair price or inflated by pasting the description, avoiding the hassle of entering mods by hand.

I have several enhancements in mind to expand this, but its development will hinge on community interest and adoption. If it helps your gameplay, consider mentioning it to fellow players.

Feel free to post any thoughts, feedback, or feature requests below - I’ll check and respond to all of them.

Keep grinding safely in Wraeclast, and here’s to worthwhile drops!

The link: https://poe2helper.com
