I really missed the speedrunning Acts quick guide from POE1, so I wrote one for POE2

Presenting the new POE2 Acts quick guide written in the same concise way as the POE1 quick guide, which helps you complete the acts in the fastest manner possible while unlocking all the skillpoints and passive buffs that you need for an endgame character.

It includes:

  • All Book of Specialisation quests which grant skillpoints
  • All quests to unlock passive boosts/buffs

It skips:

  • All quests that grant tradable rewards like orbs/skill gems
  • The treasure map quest in Act 4 that only unlocks the expedition island

I wrote this during my 2nd acts playthrough this league, and tested the steps myself, so it should be pretty efficient.

Please let me know if I missed anything or if you have any suggestions on improving the pathing thru the zones.
