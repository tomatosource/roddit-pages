Allow us to spend verisium to increase the number of runes slots in a league encounter

The league mechanic is pretty fun and has some interesting rewards but I find myself with thousands of unused verisium. It would be great to add an additional verisium sink besides runeforging gear. I think a great way to do this would be to allow spending verisium to increase the number of slots on a league encounter, thus improving the rewards. It would make seeing 3 slot encounters a lot less disappointing knowing you can upgrade them. Maybe upgraded encounters drop no verisium so you can’t just juice every encounter, and it should cost more and more verisium the higher number of slots an encounter has already. Thoughts?
