SSF Needs Some Love –Simples Ideas to Improve the Mode

Right now, playing SSF in Path of Exile 2 is an exercise in patience (and suffering). Crafting is extremely limited, every gear upgrade is a gamble, and a bad resistance roll can completely screw your build. In the endgame, it often feels like you’re just slamming Exalts and praying.

A simple way to improve SSF would be to add a checkbox when creating a character that lets you permanently lock the character in SSF in exchange for increased rare drops and currency. This wouldn’t affect the trade economy and would make SSF more viable without making it “easy mode.”

Another improvement could be making items drop already identified. Since SSF players can’t trade for good gear, this would save time and make upgrades feel smoother without drastically changing the balance.

I understand that Path of Exile 2 is balanced around trade, but that doesn’t mean SSF players should be punished. There’s a way to have both – trade can still be the best way to min-max, but SSF could get some tweaks to make it more rewarding rather than just frustrating.

I also know the game is still in early access, and there are bigger priorities right now. But if something like this gets implemented in the future, it would be a godly improvement for SSF players.

What do you guys think? Would these changes make SSF more enjoyable without breaking the core game balance?
