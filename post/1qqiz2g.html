Easy yet very lucrative Atziri rush Temple (for those who don’t know)

Example set up

For the concept how to set it up with the Sacrificial Chamber, check out the video by MisoxShiru:
https://www.youtube.com/watch?v=ZelbgpxC_ds

Important note: As you can see with my Temple the Royal Access Chamber isn’t even close to the start but that is absolutely not a problem.

-—-

Once you have that straight line to Atziri and the Royal Access Chamber set up to be only 1 tile away from the main path and connected to rooms (Garrisons, Commanders, Armouries) with the Sacrificial Chamber you can start to build secondary snakes and fodder rooms.
When built up with enough fodder you can connect to the Royal Access Chamber and basically run Atziri every Temple (with dry runs where rooms wree taken away and you not being able to re-place them with available rooms or medaillons being very very rare).

The run looks like this (as numbered above):

  1. Run towards the room connecting to the RAC grabbing the checkpoint there and complete a few rooms on the way
  2. Run towards Atziris vault and grab the checkpoint
  3. Run more rooms/secondary snake(s) to complete enough rooms to access the RAC and use checkpoint to go to the RAC
  4. When RAC activated, complete a few more rooms that are placed after the RAC for potential room medaillons (Garrisons, Commanders, Armouries to refill snake destabilizations if the normal available room options provide nothing)
  5. Use nearest checkpoint to go to Atziri and kill her

Just over the last 2 days and ~7-8h of playtime in total (including crystal farming) I was able to farm 6x chest pieces and sell them unidentified for over 3100 divs - not too shaby imo given how easy this is to set up.
