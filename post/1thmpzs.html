Please Allow Skill Gems To Be Used On Item Skills

GGG, please let uncut skill gems upgrade skills from items the same way they already upgrade existing skill gems:

  • Just use an uncut skill gem to level up the item ability (doesn’t modify the item in any other way)
  • This basically allows skill gems to act as a crafting resource as well (and provides a much needed gem sink)
  • It elegantly solves the problem of needing multiple versions of the same unique (chasing until the level 20 drops)
  • No need to add support for Jeweller’s Orbs – abilities from items (and ascendancies) already add sockets at gem level 10, 15, 20 (character level 40, 65, 90)

This small fix would make a HUGE positive impact on SSF as well as the trade economy.
