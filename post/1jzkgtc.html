Limiting 1 skill gem of each type per player LIMITS build diversity.

Think about it, how many more spells would you use if you could put your favorite gems into all the spells? I don’t even get it from a balance point of view because if a gem is so good it can’t be used twice on two DIFFERENT spells then it would be so good you’d only use the spell it is attached to currently….reducing build diversity.

Also the good gems have downsides like mana cost or dmg nerfs. You want to know what else limits this? The number of slots. 99% of peoples playtime is done with 3 or less gem slots on a spell so I really don’t see why I can’t put unleash on 2 different cold spells when the spells themselves should be unique in their use and effect not the gem.

There are just way to many negatives to keep track of on top of 1 skill gem of a type per character it really sucks the fun out of creating builds. That and an inability to reliably test a build but that is a post for another time.

Does anyone actually think this would break the game?
