Ascendancy idea for Monk

Martial Artist. Simple as it sounds. The first ascendancy would grant you an active skill: Martial Combo while also giving some % to attack speed and dmg. The Martial Combo skill would be a bare hand skill that would make you perform a combo. This combo would have like 3-4 sequences and would receive 8-10 separate support gems that would change how the combos behave and what moveset they have. Wanna do a big chonky punch build? There is a red support that will change the skill into a big slam, green support would make it into a fast kungfu combo, blue support would make it into some kind of ki blast projectiles etc. The ascendancy nodes would have stuff supporting different playstyles.
