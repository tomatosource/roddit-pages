CPU spikes

Hey, I’m asking for the Community’s help.

Since 0.3, my game has been suffering from CPU spikes. Back in 0.1 I already had this issue, which caused me a ton of deaths in endgame, but I blamed it on my old setup (RTX 2070S, i5-9600K).

Four months ago, I completely upgraded my PC (RTX 5070 Ti, i5-14600KF) — a big step up — and I thought it would finally fix the problem with 0.3. But no. The game runs smoothly at a constant 165 FPS, yet I still get these CPU spikes.

Sometimes there’s a pattern: when bosses talk in chat, when I pass a level, or when a boss attacks. But not always — it can also happen when I pick something up, when I attack, or completely at random.

For the last 2 weeks I’ve been searching Reddit for solutions and tried a lot of things:

  • Put a high number in Global/Trade chat, do /clear every hour.
  • Lowered character voice volume, disabled reverb, enabled “disable gameplay event voice” and the setting below it.
  • Set both poe2.exe processes to high performance.
  • Limited CPU core allocation (14 instead of 20).
  • Deleted shader cache and client logs.
  • Tried Vulkan.
  • Updated all drivers.
  • Lowered all settings, capped FPS at 60.
  • Allowed 100 GB shader cache in Nvidia Control Panel.
  • Set CPU priority to Real Time.
  • …and some other tweaks I can’t even remember.

The issue is exactly the same on two completely different PCs, and I’ve seen multiple people reporting the same problem.

So my question is: does anyone actually have a working solution for this?
I’ve been back on the game for 2 weeks trying everything I could find on Reddit. I know the optimization of this game is terrible and the chat log management is even worse, but maybe someone found a real fix?
