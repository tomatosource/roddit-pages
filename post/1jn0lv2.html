POE2 Price History Dataset Released

Hey everyone! For those who’ve been using poe2scout.com during the beta, I’ve decided to release all the price history data I’ve collected. The dataset covers both Standard and Hardcore leagues, with prices normalized to exalt values and includes basic quantity tracking.

If you’re into market analysis or working on machine learning projects for POE2, this data should be pretty useful. I’ve seen quite a few people asking about economy research and price predictions, so hopefully this helps with that.

You can grab the dataset and check out the documentation here: Caidora/Poe2ItemPriceDump Let me know if you end up building anything interesting with it!
