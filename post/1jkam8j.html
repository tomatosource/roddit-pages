Basic Crossbow Skill

So I have been primarily using the Basic Crossbow Skill in this game and have made it to level 88. The reason i chose it was because I hate dealing with Mana issues and honestly it’s fun to me to use an off meta build and try to make it work. As I am continuing on this journey, I have noticed a couple issues/challenges that are not making sense to me.

  1. when adding scatter shot why does the weapon use up its actual bullets instead of just adding 2 additional bullets? I believe for any other skill, it just adds bullets to each shot without removing them from the mag. But for Basic shot, you have 7 bullets and it will shoot 3 then 3 then oddly enough 3 again. So it shoots 9 instead. Would be great to just make it function like others.
  2. Reloading is odd. I’ve reached a point where my reloading can’t be improved unless I get a acceleration shrine. I can add the support gem that improves reload and take the reload nodes in the tree but the animation does not seem to get improved. I could be wrong but based on what I am seeing and hearing, I can add more but it doesn’t have any effect.
  3. adding the 5th link socket. I’m not sure why it takes level 90 to get this extra socket. The investment it takes to make a basic skill viable in end game is already hard enough so not sure why the skill is gated behind such a high requirement to get the last gem. Maybe add different types of basic shots that come on cross bows similar to spell weapons and have them upgrade the sockets based on the level of the weapon.
  4. why does it have the AoE tag?
  5. why does it not have the physical tag?
  6. what does improved gem quality do for the skill? If nothing can it do something like maybe help with skill speed

Having fun trying different builds and still learning. Looking forward to the update.
