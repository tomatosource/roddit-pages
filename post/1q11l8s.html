Mirage Archer skill missing cooldown from the description

https://preview.redd.it/3evpovc6tpag1.png?width=1920&format=png&auto=webp&s=1b0cd94c385b653051113fd1361148f47c4e7ce7

I was wondering why my Mirage archer works so badly (low uptime, too long waiting for new mirage to spawn), trying different supports and figuring out how exactly it works. I did not read patch notes and other meta, because I enjoy reading skills in-game and figuring out cool interactions by myself.

It turns out, every mirage has a duration, which benefits from skill duration modifiers, and spawning mirages has a cooldown (which is not present in skill description) and benefits from cooldown recovery modifiers. These two are separate stats, and cooldown is not listed anywhere in skill description.

Having cooldown less than mirage duration will allow multiple mirages to spawn at the same time, base cooldown seems to be 10s. Having Cooldown recovery II will decrease cooldown to 7.69s (I don’t get why, since I don’t have other modifiers on cooldown recovery, so I thought it should be something like 7s, so if anyone can help with math in comments - appreciate it very much).

Final thoughts:

- Skill description does not list important details on how it works

- It would play much better if we could reset mirage by dodge rolling, rather than by waiting for cooldown to expire. I would make it a Limit-based skill, rather than cooldown-based. Spirit cost would be fine IMO if it worked that way, for now it’s too inconvenient for its cost.
