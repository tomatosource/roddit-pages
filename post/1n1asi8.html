GGG Why does Leap Slam target units instead of the ground?

In the latest update to the Patch Notes they’ve added this:

Added a new Aiming Mode Input option that allows you to pick between Cursor Targeting and Ground Targeting when using a mouse and keyboard. Cursor Targeting causes skills that travel directly forward (such as most projectiles and strikes) to pass directly through your cursor’s position. Ground Targeting (i.e. the pre-0.3 targeting behaviour) causes these skills to pass over the ground location targeted by the cursor. Skills that directly target the ground will do so at your cursor’s location regardless of this setting. By default, Cursor Targeting is enabled for WASD and Ground Targeting is enabled for click to move.

This means either some skills that SHOULD target the ground don’t, or that they all together don’t follow this behaviour when having an enemy targeted, important vs bosses. If anyone can do other tests would be cool, I guess curses would be an obvious “should target ground”? Don’t know
