Stash - Hotkeys for Tab Navigation

There are currently hotkeys to page through stash tabs quickly by using the left and right arrow keys, however, there isn’t a way I’m aware of that allows you to page through tabs within a stash folder without using your mouse.

*e.g.,* shift *or* control + arrow key to page through tabs within a folder

If this doesn’t already exist, I think it could be a valuable addition - especially for anyone with a large quantity of stash tabs in use.

If a method for this does exist, or if the setting is configurable and I’ve missed it, please let me know! I’d love to be wrong and make use of any existing QoL functionality.
