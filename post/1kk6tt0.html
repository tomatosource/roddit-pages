Lich builds that don’t use contagion?

Tried a contagion dot build for a while but I didn’t really like it since I find it inconsistent for mapping so I left the league for a bit.

Wondering if someone here has can vouch for other lich builds since I’d like to avoid being baited in something that doesn’t work.

I tried looking at uniques to see if there was something potentially interesting to cook with:

  • Indigon: very strong in poe1 albeit a bit clunky to use. At a glance it seems only ~10 players use it on poe ninja. I would have guessed it would have worked nicely with the high regen Lich can achieve from hp but I guess it didn’t work out in the end?

  • Leopold’s applause: these seem really strong but perhaps they lose against maligaro’s virtuosity for the slot? Very few people are using these too not sure why.

Most popular build options that exclude contagion on poe ninja see to be:

  • storm mages: seems like an average minion build. Looking on YT it seems to have mediocre clear and dps from what I’ve seen. Some builds add Terracotta spectres. Really surprised no broken spectres were found btw.

  • Chaos ignite incinerate: not sure about the clear since you spend most time slowly walking to cast incinerate. Some variants use whirlwind to carry the ignited ground but I wouldn’t want to do that tbh.
