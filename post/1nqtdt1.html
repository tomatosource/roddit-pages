Undying Hate desecrated notable trade site cheat sheet

As some people may have noticed, it is not currently possible to search for specific desecrated notable affixes on Undying Hate. You cannot put anything into the search bar, and using “filter by item stats” creates Unavailable Stat when it tries to get passed in. It reminded me of Prism of Belief from 0.1.0, which I also helped crack before GGG structured it to be searchable.

I decided to mess with the ID lengths of this “Unavailable Stat” to see if it affected the outcomes, and it turns out that it indeed works as a consistent stat.

Here’s the spreadsheet. On it is the ID number used, as well as a hyperlink to the site with each notable preloaded. If the link doesn’t work or you’re looking for one with two specific notable replacements, there is a 4 step guide to replicate this behavior for yourself.

This should increase the general value of these items since players will be able to find them more easily.
