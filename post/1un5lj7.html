I see people are still confused about Mageblood’s. 2x Jade + 2x Gold gets the same bonus as 3x Jade + 1x Gold.

If you have an egg and get another egg, you now have 1 duplicate of an egg. If you get another egg after that, you now have 2 duplicates of an egg, not 3 duplicates. The first egg doesn’t count as a duplicate.

Example A,: Mageblood with 2x2x: Jade + Jade = one duplicate, Gold + Gold = one duplicate, add them together and you have 2 duplicates.

Example B: Mageblood with 3x1x: Jade + Jade + Jade + Gold = 2 duplicates of Jade, so it gives the same bonus as Example A.

Example C: Mageblood with 4x: Jade + Jade + Jade + Jade = 3 duplicates of Jade, so now it gets the increased effect bonus 3 times.

Example D: Mageblood with 1x1x1x1x: No bonus to the mods.
