# The build

The build is a Gas Arrow build (transitioned from Lighting Arrow at level 28) and can be leveled (!) with any class and ascendancy. Some of them contribute more to the build, some less, some not at all. In fact, both the Warrior ascendancies contribute nothing to the build (except for 15% inc more life on the which is whatever) which is why I didn’t even ascend at all. You can pick whatever ascendancy skills you prefer (or need later for your actual build) - it will not impact wether or not you will be able to reach level 90 (but it can make it easier, of course).
