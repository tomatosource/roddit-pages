‘Exhaust All Power’ Oracle node (from Unseen Path) doesn’t do what it says

I planned my build around this interaction, and the node does not do what it says.

Exhaust All Power, Northwest of Druid start

In PoE terms, +% crit chance adds base crit chance to any abilities it affects, which is a very strong stat. This node jumped out to me because +30% is an obscene number, and would make it possible to cap crit chance with moderate investment while archon form is active. Compare the wording of this node to the wording of ‘Struck Through’, which correctly adds base crit chance to attacks:

Struck Through, East of Ranger\/Huntress start

The only wording difference here is the word ‘to’, otherwise these appear to be the same stat. However, with ‘Exhaust All Power’ allocated, my character is gaining 33% *increased* crit chance (I have one 10% increased effect of archon buffs passive). You can see in the image below that firestorm goes from 10.29% crit chance to 12.6% crit chance when archon activates.

Firestorm crit chance without Elemental Archon active

Firestorm crit chance with Elemental Archon active

This is very disappointing as I was excited to build around the huge crit chance, but it is also just incorrect. Either the passive node needs to be re-worded to accurately reflect the buff it is giving, or the buff needs to be fixed to grant what the passive says it does.
