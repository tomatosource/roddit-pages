In the next patch GGG should make Towers work like The Grand Project

After the change they did in 0.3 towers have no real function anymore (except revealing portion of the map) and are not really needed for the end game mapping. Using a Grand Project tablet is such a huge change of pace for mapping as you get the freedom of running the maps you like and ignoring annoying maps you normally just endure to beeline where you want to go (This is especially valid when you have to maneuver around/within corrupted/cleansed areas).

It’s really sad that such a huge game play improvement is gated behind RNG (to find the tablet) or high market prices. I think it would benefit the end game and give towers real purpose when they would function like the Grand Project tablet (being able to reach any map in radius) once unlocked.
