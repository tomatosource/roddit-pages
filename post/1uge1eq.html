Jalen Duren’s playoff stats at age 22 vs other centers is not great

I’ve shared this with the Pistons sub before; the “he’s only 22” comment gets brought up a lot about Duren’s development. So it made me curious about how he stacks up with other big men in recent times.

Duren this past playoffs averaged 10.2 points / 8.5 rebounds / 1.2 blocks a game. Also remember this is his 2nd playoff run, not first.

Jarrett Allen (age 21): 10.3 / 14.8 / 1.8

Evan Mobley: 16 / 9.3 / 2.2

Alperen Sengun: 20.9 / 11.9 / 0.4

Bam Adebayo: 17.8 / 10.3 / 0.8

Joel Embiid (age 23): 21.4 / 12.6 / 1.8

Deandre Ayton: 15.8 / 11.8 / 1.1

Yea he’s still just 22 years old, but he has 4 years in the league already. Development is not linear, but it is also not guaranteed. I don’t think it’s ridiculous at all for the Pistons to want to ask for a discount based on Duren’s playoff drop.
