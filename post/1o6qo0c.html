Windows accent color set to automatic causes micro stutter ingame

Just a heads-up for anyone experiencing micro stutters in games on Windows 11. This turned out to be a Windows issue, not a game-specific one (so not GGG’s fault).

I was troubleshooting persistent micro stutters and started timing them to find a pattern. While they didn’t occur at fixed intervals, they did seem to align with specific minute marks, like 05:00:00, 21:00:00, 24:00:00. This felt too consistent to be random.

Initially, I suspected server load balancing or instance offloading, especially during peak times. But during one of my tests, I noticed that the stutter coincided with Windows changing the accent color and background (I had it set to automatic and diashow as I have an OLED monitor, which have a higher likelyhood of burn-in). I thought it was a coincidence, but I kept monitoring it.

Sure enough, every stutter matched a color change, five times in a row. I switched the accent color setting to manual, and the stutters stopped completely.

To confirm, I tested across multiple games: POE2, POE1, and Hellclock. All showed the same behavior: stutters when accent color changed, smooth gameplay when set to manual.

Conclusion: Windows 11’s automatic accent color change causes a small system interrupt that affects games, but not other applications. If you’re experiencing unexplained micro stutters, try setting your accent color manually if it’s on automatic. I don’t think a lot of people will run in to this issue as there a few prerequisites (windows background set to diashow and accent color change set to automatic based on the background image).
