An idea on how to fix the “combo” combat style

I’m not a huge fan of the “combo” system GGG is trying to make in POE 2, not because the idea is inherently bad, but because in my opinion the combos right now are restrictive and based around the wrong stuff.

It boils down to applying ailments that have a reaction in the most effective way possible ( or consuming charges ).

The issue is that it takes away from playing the skills: you don’t use the skill because it’s fun or you like it but because it’s the best at applying [insert ailments/status] and it also makes it so essentially skills are just different flavor of applying said status effects.

And after giving it some thoughts there’s so many ways to improve it without losing the “combo” aspect.

Firstly, put back some power in the base skills, i think your main skill should be able to tear through whites pretty easily ( 1 to 3 hit max ) without having the need to rely on anything else.
Combos should not only grants more damage in forms of numerical value, an idea i like would be to “link” skill together adding incentive and more creativity in builds :

For example, have some support gems trigger additional stuff if meeting a condition such as :
- triggers X after using [skill type]

Let’s say i want to use ground spikes together with a warcry as my main dps option cause i like the interaction but i dislike using earthshatter but i really like leap slam ( currently i’d have very few options that feel good )

Earthshatter X times =&gt; spikes =&gt; warcry ( not very exciting and i don’t like it )

if i had a gem that would make my next slam skill spurt out ground spikes after using the supported skills it would already make a huge difference, now i can litterally pick my prefered filler skill, then leap slam into a skill that detonates spikes.

any supportable skill =&gt; any slam ( leap slam ) =&gt; spikes =&gt; warcry ( starting to get a bit more fun and opens up for creativity )

Now let’s say i don’t like having to use warcries manually, just add a [skill gem/unique/support/alternative skill gem (like in poe1)] that makes it so i can only use 1 warcry, but that warcry will be triggered when doing [slam/melee/shield/movement] skill ( or it could also be trigger armor break, there really is room for pretty much anything )

any supportable skill =&gt; any slam =&gt; spikes =&gt; any supportable skill

Im still doing the same combo as earthshatter warcry but i have agency in HOW i want to do the combo, and if i don’t like spikes ? again just introduce an item/skill/support that would for example take the spikes and turn it into just one big aftershock or a “vaal” skill that would gain stacks instead of making a spike and do a big slam ( with more dmg / aoe the more stacks it had )

any supportable skill =&gt; any slam =&gt; stacks ( instead of spike ) =&gt; big slam

and this are just some rough ideas without too much thought put into it, you could also have an elemental skill that would change behavior based on the type of elemental spell used before and so on.

Thoughts ?

TL;DR : make the combos revolve around skills more freely, have interactions ( i.e spikes + warcry ) be the cherry on top instead of the main focus and let the players decide how and when they trigger it.
