I’ve been running into a weird issue with my GPU where performance is super inconsistent. Sometimes games run great, and other times the FPS tanks for no obvious reason.

I grabbed two photos (sorry, couldn’t screenshot) from the same game — this happens both in the menu and in-game:

  • Bad run: ~81 FPS, GPU power draw ~235W, GPU utilization 100%.
  • Good run: ~212 FPS, GPU power draw ~360W, GPU utilization 99%.

The only big difference I can see is the power draw. When it’s pulling ~360W, the card performs as expected. When it’s stuck at ~230W, FPS is cut nearly in half.

  • Restarting the computer sometimes “fixes” it for 15 minutes to a full session, but it’s inconsistent.

I tried

  • Disabling V-Sync / Adaptive Sync

  • Switching between DX11 / DX12 / Vulkan

  • Making the Windows use high perfomance

None of these made a difference.
