Fast changes are why I bought EA and I’m so glad we’re finally getting them

I understand the game isn’t in a great place right now, but this doesn’t bother me at all now knowing that GGG is finally starting to use EA like it’s supposed to be used. Fast iterations, weekly (shit, daily it seems) balance changes with the community giving feedback and reacting to the changes. None of that “we’ll wait for an economy reset to change stuff” and in the meantime everyone is just using herald of ice for months.

We got through the initial “freeze” phase, and the second inevitable phase which was the economy reseting with the absolute lowest level of power to avoid having to nerf shit.

Now, we’re finally getting to the good stuff, and I hope it keeps up without waiting for new leagues, even for nerfs if needed. This way, the game will evolve and get better way faster.
