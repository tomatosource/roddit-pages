Since 1984-85 season, Jimmy Butler is the first player to have a 30+ point triple double game with 0 fouls and 0 turnovers. In fact, there have only been 5 players since to have ever had a triple double with 0 fouls and 0 turnovers. Butler did it twice, both in 2024 calendar year.
