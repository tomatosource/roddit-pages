I think I finally figured out why mapping feels bad

Let me start by saying I am a huge Stan. Variance and rng will likely be part of my epitaph. Read most of my replies for proof.

But..

Mapping was an oasis of control in an otherwise chaotic game of poe1. You could run the map you wanted to run doing the content you wanted to do. All other rng things may have been out of control but by god if I wanted to run breach on strand for 100 maps, I could.

The poe2 mapping system takes away the last bit of control. If I wanted to run breach on Savanah for a few maps. Maybe I can… maybe. Let’s run to the tower cluster. Hope that some of the maps are Savanah’s. Run non Savanah maps carefully leading to the towers. Run boring ass towers. Insert breach tablets. Hope that they hit Savanah’s. That’s counts 5-6 steps and I can control hope and navigation. 4 of those steps, importantly, I’m spending not running the content I want to run.

It’s insulting. I don’t care about the grind or the boring ass towers. It’s that to do the thing I want to do I have to jump through hoops and disengage with content I want to do to set up the content I want to do. And you had it perfect in Poe1.

If we must engage with this system, please figure out layout targeting. I hate to be a solutioner but irradiated precursor tablets are pretty underwhelming. Savanah’s precursor tablet of quant and rare monsters sounds super sexy. Changing x eligible maps To the layout you want would go super far. Wouldn’t fix towers but it would throw us a bone.

End rant. Totally not my style sorry guys. It finally clicked that I feel jerked around in the atlas and had to put it somewhere. Thanks. End
