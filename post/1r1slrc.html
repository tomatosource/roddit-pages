Indigon Oracle (Arc)

6mod T16: https://youtu.be/b4WINMRknSg?si=FVwQytpswkw4Ay2H

Uber Arbiter kill: https://www.youtube.com/watch?v=aOr8vzSLoEg

Theres still tons of ways to optimize this.

The core is Indigon helmet (buy the lowest mana cost one you can find) + Kurgal Undying (cheap) + Quipolatl inside Darkness Enthroned belt. You can run HH with this if u want then you need a 60% effect glove to put the rune inside. But I do think this setup is better since you can get higher mana pool this way, as well as more mana regen. Anoint a mana cost efficiency node. Heart of the Well with Mana cost efficiency is also nice.

In the buid I have suboptimal life rings as well, the 3 best stats on it is Max mana/Int, Inc %Max mana and Mana regen.

It’s not the cheapest build to set up, but you 100% don’t need to run it like I do, I have just minmaxed to the extreme. Build is very flexible and theres many ways you can set it up. Mana + Mana regen is your two best stats. 4.7m on Curse is also very good for bossing (this is how you oneshot bosses with the build), but curse AoE is not mandatory for mapping. Focus on getting a big mana pool with good regen first.

So this build gets up to 100k mana regen, 5000% spell damage. It oneshots all rooms in temple, it oneshots bosses (even Uber Arbiter as you can see on the video), it clears multiple screens if it is allowed to chain. And build is surprisingly tanky, and only gets tanker the more mana you get. If you do get stunned rour mana regen + Arctic Armour with Knockback usually keep you alive until you can move/cast again. Build has everything.
