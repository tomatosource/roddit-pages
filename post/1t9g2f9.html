I’m just curious, is GGG working on a full controller and mouse/keyboard switch? (with UI)

I think it would be enough for us if we got one extra feature: to be able to use the mouse on the hideout or stash management (there are stash in several places)

(control + click and etc.).

I don’t think a full switch is needed.

If you look, there is already a mouse cursor and it works. You can switch tabs with it.

If you move around in the inventory with the controller and click anywhere with the mouse, the yellow square disappears.

There are two problems:

**1:** If you grab something with the controller and want to switch to the mouse.

Solution 1: In this case, you can’t use the mouse.

Solution 2: Clicking the mouse will cancel and return what you grabbed to its original location.

**2:** If you grab an object with the mouse (there is currently no such feature) and use the controller at the same time

Solution: As long as you grab something with the mouse, the controller does not work

Jonathan would probably say that this is only a half-solution. I don’t think anyone needs more than that.

There is no need to work out the full switch. Those who play with a controller don’t really want to switch to keyboard/mouse.

Just a quick inventory management and we’re back to the map.
