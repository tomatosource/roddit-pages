Tower Juicing Idea: Reduced Chores, More Metagame

Endgame Idea: Reduced chores. More metagame.

I’ve been enjoying 0.2 since the first patch, but having to setup maps still makes me not want to login.

Core Changes

A map can only be in range of a single tower. Or can only be influenced by one.

Towers can take up to six tablets. (Could do more, but assume six for now)

Tablets also increase difficulty. Rewards scale slower than the difficulty. So running all 6 tablets is aspirational.

Balancing

A build is good if it can run 4-5 tablets endgame. It’s good if it can clear 6 tablets with giga gear.

It should be nerfed next league if it can clear six tablets without giga gear.

It’s imperative that full tablet juicing is not too profitable to the point that people who juice 3-5 are making pennies. Although it obviously doesn’t solve the issue, it helps fight super op builds that slip through from destroying the economy.

Difficulty scaling can be simple – similar to deliriousness (i.e. more damage taken, less damage dealt) – or more complex like map suffixes. However map suffixes is not the right way as some builds can avoid some suffixes. (Some don’t care about curses, some don’t care about chaos damage, etc.). We want difficulty to be felt.

Intended Mapping Flow

Tablets should have more diversity, and should be much rarer. Since tablets are so rare, you need to target farm them (to not be locked into trade).

The mapping flow is like this:

  1. Setup a tower with increased tablet drop chance, but not as much as of other goodies. Clear maps to build up your tablet inventory.
  2. Craft, reroll, trade, etc. for good tablets. Ideally step 1 is enough to not trade. But not so much that you never need to run Step 1 again.
  3. Setup a tower with quant/rarity/league mechanic/etc. juice. Clear maps for currency

Step 1 and Step 3 are both dopamine inducing (tablets and divines play sexy tunes when dropped). Neither step is a chore to setup: No unrewarding gameplay needed. Path to a tower and you’re done.

If you don’t like step 1, you could always buy your tablets. If you love step 1, you could just farm tablets for profit.

Leagues

Over the next leagues, introduce mechanics that scale well with tablet farming but not as well with other farms. So the map gameplay of tablet farming and currency farming can diverge over time.
