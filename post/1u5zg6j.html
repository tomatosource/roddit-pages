Would anyone else use an Atlas Route Queue?

One thing I’ve noticed while mapping in PoE 2 is that if I already know where I want to go on the Atlas, I still have to repeatedly:

* Open Atlas
* Find the node
* Select it
* Put in a Waystone
* Enter map

After a long mapping session, it starts feeling like unnecessary extra clicks.

What if there was an optional Atlas Route Queue where you could plan multiple Atlas nodes ahead of time?

For example, I could select 10 connected nodes and set the order I want to run them. After finishing a map, the next node in the queue would automatically become the default destination for the next Waystone.

You could still manually select another node at any time, so it wouldn’t remove any player choice or automate gameplay. It would just make mapping feel smoother for players who already know the route they want to take.

I don’t think this would affect balance, rewards, or progression in any way. It would just be a QoL feature that cuts down on repetitive Atlas navigation.

Would you use something like this, or is there a downside I’m not seeing?
