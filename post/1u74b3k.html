Modifier information

This post was inspired after alt tabbing for the 5th time to poedb while trying to use whittling omens.

As it stands right now, the omen of whittling design is terrible. It says, “your next chaos orb will remove the lowest level modifier”, but there is no way, in-game, to see what lvl any modifiers are. The only way to check if you can whittle mods is by looking at a third party website like poedb or craft of exile. This is 1) bad for new players who don’t know about/don’t want to use these tools and 2) annoying for anyone.

More generally, I think poe 2 needs much better communication about modifier information. There should be a way to see what lvl different mod tiers are in game, either on the item or in some in-game recipe book or something. I also think that we need to be able to see the tags of different modifiers. In poe 1, you can see the mod tier as well as the tags like caster, attack, speed, etc. This is very useful when using things like catalysts that interact with specific mod tags in different ways. In poe 2 rn, all we have is mod tier, and information that is required for using crafting materials is literally hidden from players in game.

Edit: I know you can see what mod is going to be whittled off when you hover a chaos orb. My point is that you shouldn’t have to pay 6 div to see if you can whittle or not.
