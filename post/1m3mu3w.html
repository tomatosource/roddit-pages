QoL suggestions for 0.3

With 0.30 about a month out, what are some QoL changes you hope could be implemented? Minor changes that’d be easy to implement and wouldn’t affect balance/gameplay/art/etc.

Here’s a list I gathered from my own and other players’ suggestions; here’s to hoping some of this can make into 0.30:

  1. Improve contrast for mod tier text and lines.

(The dark bronze color on translucent background for mod tier text and the dividing lines between mods is hard to read/see)

  1. Simulacrum and simulacrumbs auto-send to Delirium tab.

(Simulacrum and simulacrumbs (splinters) currently get sent to fragment affinity tabs. Why? There’s a space for these in the Delirium tab, so that’s where they should go.)

  1. Improve the weapon set color contrast in the passive tree.

  2. Improve visibility of objects within blast radius of expedition charges, and improve visibility of circular blast radius indicator.

  3. Drop-at-end splinter mechanic for all splinters (for example, for delirium, including for emotional waystones)

  4. Apply distilled emotions the same way currency can be applied (with a right click)

  5. Boss icon revealed from the start of a map.

  6. Ctrl + click to send a currency from inventory to the Alva window (as is possible in PoE 1 Settlers league).

  7. Have a customizable favorites tab in the currency exchange.

  8. Fix symbol overlap in minimap (for example, when rare monster symbols and ritual symbols are both far away, only the ritual symbol will show, with the rare monster symbol being invisible).

  9. Speed up the recombination animation.

  10. Show mod ilvl.

  11. Option to toggle off clickable keywords (helpful in expedition and simulacrum for example).

  12. Reduce overlap between stash/portal/initiation window in simulacrum (the stash especially is often hidden).

  13. Indicate suffixes and prefixes when holding alt (as is already done with the trade site).

  14. Icon indicating which weapon set is currently active.

  15. Add minimap icons for mechanics (ritual, breach, etc) once the map is complete.

  16. Streamline reforging bench to a vendor window so multiple items can be reforged at once (as in PoE 1).

  17. Allow distilled emotion upgrades in the stash tab (as with PoE 1).

  18. Add a search bar in the ritual rewards window.

  19. Maybe a heavier lift, but delirium fog is still a pain point for many (all?) players, especially in distilled maps.

And don’t leave the console folks behind!
