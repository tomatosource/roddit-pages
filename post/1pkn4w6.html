Long-time M+KB player blown away by how well the game feels with a controller

So I’m a long time mouse + keyboard player and across the last two years a long-term shoulder issue has started giving me progressively more hassle. So much so playing for extended sessions like during league starts has become an issue.

Today I decided to buy a controller (GameSir G7 Pro) to give it a go with the upcoming league start and goddamn have I been blown away by well this game plays with it! I tested it across various characters and feel so much more in sync with the character and abilities. I should’ve done this a long time ago.

If anybody out there is wondering about switching over to controller, I’d say don’t hesitate. Not sure if it was the case with previous leagues, but it works seamless.

Excellent work GGG.

EDIT: … Now please give us hot swap for inventory management.
