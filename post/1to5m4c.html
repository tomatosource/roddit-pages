I made a skill tree comparison tool for 0.4 vs 0.5

Hey everyone,

I was curious about what exactly changed in the skill tree between patches so I built a quick visual comparison tool. It puts both trees on top of each other with a slider — drag left to see 0.4, drag right to see 0.5. Makes it really easy to spot moved nodes, new connections, etc.

Link: https://oguzhanvarsak.dev/poe2-tree

Features:

  • Overlay with draggable slider

https://reddit.com/link/1to5m4c/video/zw6mbrwteh3h1/player

https://preview.redd.it/pz025f8q7h3h1.png?width=5120&format=png&auto=webp&s=8c4151aadc5bc8918d4ac5f70822f9fd3c574742

  • Search to find specific nodes/stats

https://preview.redd.it/lnrca0cs7h3h1.png?width=5120&format=png&auto=webp&s=6b16c83863c3527973834342b87eb429f59387e4

It pulls directly from GGG’s official skill tree export on GitHub so the data is accurate. Built it mostly for myself but figured others might find it useful too.

I’m planning to add the ability to pick any two versions to compare (not just 0.4 vs 0.5) and an overlay mode where you can see both trees blended together to really highlight the differences.

Let me know if you run into any issues or have suggestions!
