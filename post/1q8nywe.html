new command line parameters (most old ones don’t work anymore)

I tried making my in-game experience a bit smoother by trying the tried and true –waitforpreload and –noasync parameters, but couldn’t see any difference. Looking through the game log file located in &lt;POE2 install folder&gt;\logs\LatestClient.txt also confirms with entries such as

\[CMD\]\[Unrecognized\] --waitforpreload  
\[CMD\]\[Unrecognized\] --noasync

So I dug through the executable using ProcessExplorer and found the following:

Disable NVidia related functionality (DLSS/Reflex/etc)

\--no-nv

The login server port

\--login-port

The patching server that should be patched from

\--patching-server

Override basic auth used for for patching content

\--patching-auth

Before running wait for this process id to exit.

\--prev-proc-id

Require that the user press the launch button in the patcher before entering game

\--require-launch

Fail horribly

\--fail

Disables the creation of the audio device

\--nosound

Forces use of generic software audio device

\-swa  
\--softwareaudio

The handle to an inherited event object that will be signaled when startup has successfully been completed

\--success-event

Disables the 24H2 Single Threaded Loading workaround

\--24h2-mt

Use many more job queues to test contention

\--test-job-many-queues

Disable D3D12 render separate transfer queue

\--test-disable-transfer-queue

Disable the custom memory allocator and use the standard allocator instead

\--test-std-alloc

Add extra checks when finding binding sets

\--test-validate-bindings

Synchronize CPU and GPU work

\--test-single-buffered

Forces UI to be updated before other jobs

\--test-synchronous-ui

Forces simulation to be updated before other jobs

\--test-synchronous-simulation

Disable engine frame move high jobs

\--test-disable-frame-move-jobs

Disable engine frame render high jobs

\--test-disable-frame-render-jobs

Batches descriptor copies per frame

\--test-batch-descriptors

Force the use of the safe frame graph

\--force-safe-frame-graph

Enable the device resource manager

\--device-resource-manager

Disable static entities prefetching

\--disable-static-entities

Keep all resources alive for existing descriptor sets

\--descriptors-keep-alive

Validate descriptor lifetimes

\--descriptors-validate

Flush descriptor set cache frequently

\--flush-descriptors

Flush resources caches frequently

\--flush-resources

Disables render device recovery in case of a device lost error

\--no-device-recovery

Skips intro video

\--nologo

Launch game with kakao authentication

\--kakao

Disable the custom assert mesage box

\--disable-assert-box

Used by Epic Games Store launcher
Sets the language based on the given language name or language code

\-lang  
\--language

Will always use default settings set in the settings.cpp

\--use-defaults

Disables the automatic client switching that occurs when the wrong client is started for the current user DirectX setting

\--dcs  
\--disable-client-switching

Since the old fan favorites like –waitforpreload and –noasync aren’t listed, it’s safe to say they don’t work anymore (at least with the version of the game available at the time of this posting).

As for the new parameters, I have no idea what most of them do and the description supplied isn’t of much help, at least to me. Perhaps some of you have the knowledge or experience or exploratory drive to figure this out.
