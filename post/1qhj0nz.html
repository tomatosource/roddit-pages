As you can see you see the avg go up and down. These low run with 0 and 1 dropping are a little annoying but never got me close breaking chain. I think i’ve done 300+ runs thus far since reaching fully min/maxed layout. I started tracking spreadsheet since 50 runs ago. The data does represent something I’ve been thinking, personally i’ve been thinking an average around 2.5. Usually a low run is countered with at least a run with 2 locks or better. This does really make 2 chains definitely sustainable and you could argue if you’re at 6 locks it’s okay to tri lock with some risk though.

I’ve heard stories of people struggling with locks so my experience could be different from other. I still can attest after 300 runs though this 50 run data pretty much represents what I’ve been experiencing. I don’t know how helpful this data is but always fun to see some data and insights.
