Delirium encounter is not in a good place

First of all, juicing maps with distilled emotion automatically invalidate delirium encounter and its reward.

Secondly, delirium encounter doesn’t scale well with end game min-maxing. Let’s say you stack multiple towers with all the delirium juice it’s still very hard to make a huge difference because it takes exponentially more kills to add another stack to the reward. I think all the juicing I did only add one more stack from 6 to 7 compared to quantity stacking which can easily double your loot.
