I made a season countdown tracker so I could spend more time in maps and less time on Google (Maps?).

Hey all, I built a small side project called SeasonDex that tracks season dates and countdowns for PoE 2 and a handful of other ARPGs.

Basically I got tired of googling “when does the current PoE 2 season end” every few weeks, so I made a page that just shows it countdown timer, season history, upcoming dates, useful links. Nothing fancy. There is also user notes page for each game if you want to keep track of anything.

It also covers PoE 1, D4, D2R, Last Epoch, and a few others if you bounce between games like I do. There’s a timeline view that makes it easy to see what’s running and what’s coming up across everything.

Figured I’d share in case anyone else finds it useful. Feedback welcome if you have any.
