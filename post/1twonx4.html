Current ward system doesn’t feel rewarding at all

I collected a bunch of different skills and supports and none of them felt worth giving up on other stuff to gain ward to use it.

I think a much simpler system would have gotten the job done better.

For example supports like

- Supported skills deal 1% more damage per ward consumed, up to 30%.

- Supported skills have 2% increased area of effect per ward consumed, up to 50%.

- Supported skills fire 1 additional projectile per 100 ward consumed, up to 5.

Stuff like that. Just supports that you feel like you MUST have, but you also have to invest into ward to be able to use them.

Just felt like sharing these thoughts, sorry if someone else already proposed this.
