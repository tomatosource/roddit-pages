The few things I did to stop my POE2 crashes.

Like a lot of you, I was getting constant crashes in PoE2, and it was driving me nuts. Most of my crashes happened when transferring loot from my inventory to my stash, and once that started, I knew more crashes were coming. Eventually, I’d have to reboot my entire PC just to keep playing.

On top of that, I was also getting the usual mapping crashes and the classic crash-loop when trying to start the game back up.

Nothing I tried was working. Here’s what I did that actually helped.

My Setup:

  • Motherboard: MSI Pro Z790 A
  • CPU: Intel Core i7-14700K
  • RAM: 32GB Corsair 6000MHz DDR5
  • GPU: NVIDIA GeForce RTX 4080 Super

What Fixed It:

1. Updated to Windows 11 (23H2 - OS Build 22631.4169)

I was avoiding the upgrade forever because I thought Win10 was better for performance, but at this point, I was desperate. Turns out, PoE2 actually runs more stable for me on Win11.

2. Installed & Configured These Apps:

  • Process Lasso Pro (Free version might not have these settings available)
    • ProBalance: Helps smooth things out while PoE2 is open.
    • CPU Limiter: If CPU usage hits 90% for 1 sec, it reduces 2 cores for 10 sec. (Seems to help with stability.)
  • Kapps PoEUncrasher
    • Auto-adjusts active CPU cores while playing. Not 100% sure how much it helps, but it’s been part of my fix.
  • Intel Extreme Tuning Utility
    • Tweaked “Performance Core Ratio” to 54x. No clue if this was the game-changer, but I figured I’d mention it.

TL;DR:

I updated to Windows 11 and used Process Lasso, Kapps PoEUncrasher, and Intel Extreme Tuning Utility, and now my crashes are (mostly) gone.

PoE2 clearly has CPU-related crashing issues, so if you’re struggling, this might help. Also, don’t update to Windows 11 22H4 - I’ve heard nothing but problems with this patch.

Hope this helps someone! Let me know if you’ve found anything else that works.
