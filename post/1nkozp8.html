FPS Drop - Tried all suggested FIXES - Finally found what works for me.

First off my specs: i9 14900K - 2TB NVME SSD - 5080 - 32GB DDR5 (6200)

My monitor is 4K - 240hz.

**IMPORTANT** ONCE ALL THIS IS DONE, YOU’VE FOLLOWED EVERY STEP - YOU SHOULD BE GOOD TO GO - HOWEVER, ANOTHER THING I DO EVERY SINGLE TIME I LOAD INTO A NEW ZONE OR SOMETIMES EVEN GOING BACK TO TOWN IS HIT &gt;F1&lt; WHICH WILL BRING UP THE PERFORMANCE METRICS *Make sure to have ALL GRAPHS enabled in Graphics Settings* You will see the SHADER BAR will be FULL GREEN - This is compilling shaders - I ALWAYS WAIT FULLY UNTIL THIS HAS FINISHED - When the compiling is done, it will be empty - This helps remove any initial stutter/drops when entering a new area/map and or TOWN, town for some reason compiles shaders on every return.

Take into account my setup, your results maybe different to mine, but this should at least smooth out the game until GGG actually optimise it.

*This will only potentially help/work if you have a 40⁄50 series GPU that supports SMOOTH MOTION*

***NVIDIA CONTROL PANEL*** SET DRIVER SHADER SIZE FROM DEFAULT TO EITHER 10GB OR IF YOU HAVE PLENTY OF ROOM LIKE ME 100GB. This should only be done AFTER you have updated GPU drivers if needed, and or DELETED THE ENTIRE SHADER CACHES AS MENTIONED BELOW.

I tried lot of potential fixes that have been suggested. Helped to some degree, but nothing great.

What I did, in order you will want to do it:

Make sure GPU Drivers are upto date.

Find your Game Folder, the entire things from within Steam Folder - Go to Windows Security Centre &gt; Virus and Threat Protection &gt; Scroll to the bottom to where it says EXCLUSIONS &gt; Select it and ADD the entire Path of Exile Folder.

**DELETE THE ENTIRE NVIDIA SHADER CACHE** DELETE POE2 SHADER CACHE - RUN DISK CLEANUP, CLICK CLEAN UP SYSTEM FILES AND MAKE SURE TO TICK DIRECTX SHADERCACHE.

  1. Download either Nvidia APP (If not so technically savvy) OR Nvidia Profile Inspector

*This was the thing that after all the later changes, that in my case were done PRIOR, made the biggest difference*

  1. Go into either Nvidia APP or NPI, locate Path of Exile 2 &gt; Find SMOOTH MOTION &gt; Enable it (I noticed no major latency issues or anything else untoward)

2} Make sure REBAR is turned ON in your BIOS - By default mine inside BIOS is already ON.

  1. Using NVP go to Global Setting, set RBAR to ENABLE &gt; Go to Path of Exile 2 inside NVP, check RBAR is ENABLED here too - Then inside of the same PoE 2 profile section within NVP - Set RBAR (options) to *0x00000001 (Returnal, Red Dead Redemption 2)* then directly under it, Set RBAR Size Limit to around 80% of what your card has. a 5080 has 16GB VRAM so you would want to set this to something like 10GB - Google how to change this to suit your VRAM limit. For a 5080 e.g. you would set it to 0x0000000280000000 which would allocate 10GB Vram.

**Make sure to click APPLY twice after changing all settings** We are done with NVP/Nvidia APP

IN GAME SETTINGS: Remember my setup, yours may be able to be tweaked slightly different.

-Sound Settings &gt; Channel Count LOW &gt; Reverb OFF

-Graphics Settings &gt; Renderer &gt; DX12

Dynamic Resolution - OFF

V-Sync OFF

Window Resolution (Native so your monitor resolution)

Upscale mode &gt; DLSS

Image Quality &gt; Balanced

Sharpness &gt; Set this to your preference

Texture Quality &gt; High

Texture Filtering &gt; 2x/4x/8x doesn’t make too much difference, IMO.

Lighting &gt; Shadows (Not Global Illumination) &lt;&lt; GI big hit.

Shadow Quality & Sun Shadow Quality & Number of Lights ALL LOW

Bloom I have mine set at the lowest, personal preference.

Water detail &gt; High

Advanced Settings - EVERYTHING disabled aside from Engine Multithreading - Here I also set a forgeround FPS cap to 165 - My monitor is 240hz. I set this cap because with the aforementioned settings I can mostly stay around this number.

Anything you’re not sure off such as Clearing Caches etc just google it, lots of info on how to do it really quick.
