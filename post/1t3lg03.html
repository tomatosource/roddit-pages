Should you be doing things or should things happen

This is a weird one, but I know I am not the only one noticing a tension between poe1, eop2, how the games want you to play them and how players want to play them.

This tension has a lot of aspects, but I think a lot of it can be boiled down to do you want to do things, or do you want things to happen. Do you want to use ability A and have that set you up to use Ability B, or do you want to use ability A and have that trigger ability B to happen automatically.

This tension is weird because stuff happens is uncommon in games. Most games want you to be using abilities, but also the stuff happens style is what poe1 was built. On the other hand poe2 had a break and moved to a do things style gameplay. Some players followed and I think more didn’t.

The game doesn’t seem to want to be in or bucket or the other and is trying to be both, but that tension is very visible.
