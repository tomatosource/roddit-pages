Tactician Armour Stacker - Mortar Cannon - Weapon Swap Tech, Lightning Variant, and Fast Clear Setup

Hey folks!

Just wanted to share my current Tactician build focused on armor stacking and using Mortar Cannon as the main skill. The build’s been performing really well, and I’ve added some fun tech and QoL choices that make it both tanky and satisfying to play.

💡 Key Features:

  • Weapon Swap Snapshot Tech: Totems snapshot the weapon set when summoned, so I’m using the weapon swap mechanic to get a burst of extra damage and survivability. You summon the totems with your main set, then swap to a secondary setup for bonuses like Onslaught or defenses.
  • Lightning Conversion with Valako’s Vice: Swapped to lightning damage using Valako’s Vice gloves, which pairs great with Mortar Cannon and opens up some interesting synergies.
  • No Rakata Needed: This build works without Rakata, freeing up gear flexibility and making it more accessible.
  • Secondary Weapon Set for Onslaught: My second weapon set is stacked with Onslaught-granting effects, making mobility and DPS smoother between rotations.
  • Haste Companion Coming Soon: I plan to upgrade the setup by adding a Haste beast companion — once I find one that uses 35 spirit or less, I’ll update the post with it!
  • Explosive Clear Setup: Using Explosive Shot with the Armour Explosion combo and Herald of Thunder for super fast clear and satisfying chain reactions. It melts packs and feels great to play.
