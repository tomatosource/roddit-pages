QoL Changes

The game still needs polishing when it comes to distilling maps and reforging bench.
I am proposing the following the changes:

  1. Mass instill of waystones: This is required as it takes way too long to instill maps. Either make it so we can select the desired distilled emotion we want to add on the map and the game does it automatically. Or make it so we can drag the distilled emotion and apply it instantly on the map. Or right click fills the slots for the distillation
  2. Reforging bench: The animation is too long in my opinion. This should be reduced so more people are incentivized to reforge their tablets for example
  3. Optimizations: One way is to remove the corpses of already dead monsters after 5-10 seconds (I guess this has an overall impact of the game performance)
    Please add other suggestions below
