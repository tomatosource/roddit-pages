I think they finally nailed it with the latest changes!”

We started off with everyone abandoning the temple because of the rewards (yep, they sucked real hard), then all the temple-access shenanigans with the Holten bug. But credit where it’s due: GGG actually listened and made some solid tweaks.

That said, it’s probably now a bit too late to fully fix the economy since all that bug abusing did mess things up a lot.
