End Game Map Mechanic Count

I am curious about the patch note that 1 to 3 contents are guaranteed to generate per map in 0.3. This reads like a buff initially. But upon hearing complaints about strongbox and essence nodes not working, this reads more like a nerf.

When I think of a mechanic, I used to think of Breach, Ritual, Simulacrum, and Expedition as the core league mechanics. Strongboxes, essences, rogue exile, etc. are another layer of contents added on top. You can have both layers in the same map depending on rng and juice you use. Now there seems to be a limit on how many “contents” you can have.

Added more juice does make that 3 contents per map outcome more likely. But meanwhile, adding even more content via juicing simply means replacing what would have natively been generated with what you are added via tablets. This is made worse, if the 1-3 being counted doesn’t differential between Ritual and Strongbox, i.e. league like mechanics vs added features. If the map already has a strongbox, adding a ritual simply replaces that strongbox.

Edit 1: Sorry for the confusion, the patch note states that maps are generated with 1 to 3 extra contents including major league mechanics (e.g. breach) and other extras (e.g. strongbox). So, if the map already has a strongbox with 2 other contents, adding a strongbox tablet doesn’t do anything. Meanwhile, if you have a map natively generated with breach, exile, and essence, adding a strongbox tablet might simply replace one of the three existing ones. If this is how the game works, it could explain why lots of main map tree nodes don’t really work as well as before.
