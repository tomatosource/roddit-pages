How would you rank league starting Minions vs other archetypes

So I figured I try a minion build this league, since I haven’t played them yet in PoE2. Also reduced pack size and buffed monsters might make minions more favorable compared to the past since minions usually struggle a bit with coverage and clear speed.

To not go in completely blind I did a test run today on a Witch doing Act 1.

Result was that I was left somewhat underwhelmed. Compared to a start with Contagion + ED, various Mace, Xbow or Bow skills, it really felt like it underperformed. By the time I was done with Hunting Grounds I usually already killed the Count and move to Act2 on other non minion builds so far.

I did use Contagion to boost Unearth minions, but did not level it up as a priority.

Also used the Fire Attunement tech on Skeletal Snipers for their Gas Arrows. This also felt somewhat awkward to use ( probably misplay on my part).

So I kind of ask myself now, is that normal, do minions just suck early and might get better late game? If I am using Contagion anyway, wouldn’t it be better to just level as Contagion + ED till the point minion skills catch up?

Also on this note, will skeletal warriors at some point don’t feel like paper toys? To some extent I was annoyed how fast they died.

All my test run did now made me unsure If I really wanna start minions next league and maybe better run something weapon based like a Bear/Slam build.

Any thoughts?
