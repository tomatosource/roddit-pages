Bloodmage shouldnt be the better elemental caster, while the class fantasy is a phys caster. 15% base crit node needs rework

I love the class. The issue is the base 15% crit node which is antisynergistic to the bone spells that already have 15% crit and has super high synergies to other elemental spells.

On top of that it gatekeeps the crit damage node, so a physical spellcaster is punished for playing bloodmage whos artwork literally shows casting bone spells.

Thats why I think that specific node needs a rework. Like give it spells have +5% base crit chance or sth.. this way low crit skills would still benefit from it (not as much as now though) and high base crit skills could still use the node. Just some balancing and class fantasy thoughts.
