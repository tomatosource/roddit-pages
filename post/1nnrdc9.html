Made a small browser extension to view your stash on trade site

I saw a post here yesterday with a Suggestion to show the price you set on the items you sell at Ange. I wanted to take it a bit further and also add a good way to visualise how long items have been listed, what they are priced at and have a color code to show which items should be relisted. It also shows if you forgot to set a price to certain items and in which tab they are located.
I know all this information is already there in the list on the search if you filter on your own user, but this extension visualises it so it’s easier to crossreference.

I wish I could mod it ingame but I can’t, so instead I made it work on the trade page, this is what it looks like in action:

View of one of the stash tabs, tab names at top are matching with ingame

Example of an in person tab, tab names are at the top as ingame

This is a very rough draft that I only worked on for like 3 hours, but the idea is to extend this with price checking/suggestions so you can easy relist items ingame at current market prices, using similar filters like Exiled Exchange and whatnot. But I wanted to get a first feeling if people found this useful at all or if I’m just wasting my time :)

The extension is not published yet, but can be used already through the instructions on the Github repo

Feel free to give feedback or let me know if there are breaking bugs

One note, in person trade tabs will only show up when you are actually online ingame. Buyout tabs are always available
