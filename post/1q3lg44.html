Atlas map is a big FOMO trigger for me

I am a HCSSF player, I have 900 hours in this game and probably 600 of it spent in the campaign. Whenever I created a new character, it is easy to get it going in the campaign because there is not much options to choose where to go.

But when I reach the maps the decision problem starts. Whenever I open the atlas map I need to decide which node I need to go. At some point this is starting to depressing me because when I try to go in one direction then I see some unique map, corruption or citadel etc. on other direction. Completing these nodes also reveal other things on the side that is not where I wanted to go. This is going on and on.

I’d prefer a straightforward wide path where I have to choose a node from a 3-4 node pool instead of this circular atlas map.
