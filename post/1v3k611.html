Tablet Effect Information

*Edit: I missed one 5% effect node, math is now fixed

#Masters

  • Jado: 0-40% increased Tablet Effect, +1 map mod when corrupted
  • Hilda: 8% increased Tablet Effect per type of Tablet used
  • Doryani: None

#Atlas Passive Tree Sources:

  • 3% effect per waystone modifier (up to x6 normally, x7 when corrupted with Jado, x9 when 8-mod corrupted with Jado)
  • 5% effect per tablet (x3 normally, x4 in cities)
  • 8% effect in cities
  • 5% effect
  • 5% effect
  • 5% effect

At a baseline, this nets us 30% effect from using 3 tablets. Cities increase this to 43% effect with 4 tablets. 6-mod waystones give 18% tablet effect.

#Total:

6-mod waystone

  • Jado 3 tablets = 30% + 18% + 0-40% = 48-88% effect
  • Jado 4 tab city = 35% + 8% + 18% + 0-40% = 61-101% effect
  • Hilda 3 tablets = 30% + 18% + 24% = 72% effect, cannot use same tablet twice
  • Hilda 4 tab city = 35% + 8% + 18% + 32% = 93% effect, cannot use same tablet twice
  • Doryani 3 tablet = 30% + 18% = 48% effect
  • Doryani 4 tab city = 35% + 8% + 18% = 61% effect

corrupted 6-mod waystone

  • Jado 3 tablets = 30% + 21% + 0-40% = 51-91% effect
  • Jado 4 tab city = 35% + 8% + 21% + 0-40% = 64-104% effect
  • Hilda 3 tablets = 30% + 18% + 24% = 72% effect, cannot use same tablet twice
  • Hilda 4 tab city = 35% + 8% + 18% + 32% = 93% effect, cannot use same tablet twice
  • Doryani 3 tablet = 30% + 18% = 48% effect
  • Doryani 4 tab city = 35% + 8% + 18% = 61% effect

corrupted 8-mod waystone

  • Jado 3 tablets = 30% + 27% + 0-40% = 57-97% effect
  • Jado 4 tab city = 35% + 8% + 27% + 0-40% = 70-110% effect
  • Hilda 3 tablets = 30% + 24% + 24% = 78% effect, cannot use same tablet twice
  • Hilda 4 tab city = 35% + 8% + 24% + 32% = 99% effect, cannot use same tablet twice
  • Doryani 3 tablet = 30% + 24% = 55% effect
  • Doryani 4 tab city = 35% + 8% + 24% = 67% effect
