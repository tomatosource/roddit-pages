PSA: You have to do the optional logbook quest in Act 4 to unlock all Runeforging

This is normally an optional quest where you get a bonus logbook encounter if you happen to find the four map pieces.

This league, this quest must be done to unlock Runeforging recipes. It is done by completing the logbook encounter, then entering the building and clicking on the table inside.
