What if you could buy an extra life with gold if you die in a map?

Basically what’s in the title.

As it stands today there aren’t many endgame gold sinks other than the currency exchange fee, which is pretty trivial.

But what if when you die in a map you could revive for a gold fee? Obviously this would need to be balanced like increase gold cost based on map tier or something so that it’s still significant for skilled players but also lower for lower level players.

Since gold isn’t tradeable you’d actually have to play the game to be able to revive. So a rich player couldn’t just buy a bunch of revives.
