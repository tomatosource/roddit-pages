An analysis of mapping

OK, so this is a holistic viewpoint, stepping back from the details to examine what mapping entails.

We have an area that comprises various types of content.

We can influence this area by three primary methods.

  • The Atlas Skill tree
  • Precursor Tablets
  • Waypoints

If we step back, we can further expand this logically

  • The Atlas Skill tree is a global influence, whatever the skills do, affect all content, everywhere.
  • The Precursor tablets (at least used to prior to 0.3.1) influences an area.
  • Waystones influence a single map.

[Note, 0.3.1. changed this, and part of this post is to explains why that is a backwards step, and a temporary change)

Using these three tiers of influence, the goal of a player would be to deterministically choose a preferred type of content, and improve the rewards of that content, while increasing difficulty as a result.

That essentially is what the POE 2 mapping should be about, and the three tiers: Atlas, Tablet, and Waystones, should work to that goal.

Given this concept, there is considerable overlap in the types of influence provided, e.g. waystone drop rates are in the Atlas, on tablets, and on waystones.

Having three distinct influence tiers should result in having three distinct types of influence that each provides.

The current system is a confusing mess of duplicated modifiers applying in triplicate.

For example, right now the core Atlas skill tree has areas that increase (assuming they actually worked) the chance of some types of modifiers appearing, such as Essences, Rogue Exiles, Strongboxes etc.

These are GLOBAL changes, these sorts of changes should be for an AREA, i.e. a Tower.

Global influences should be confined to non-content specific changes that players would want to have for the entire Atlas.

The idea was for players to use the Atlas Skill Tree to set up the Atlas individually, I get that, and having specific content boosts here might work if the Atlas was not an infinite scrolling all-encompassing source of content.

Things like Waystone drop rate, waystone drop level, item rarity, item quantity are GLOBAL changes that you would want to apply to all maps, regardless of the actual content. These belong in the Atlas Skill Tree.

Towers control areas, this is where YOU the player decides what this particular area’s content will contain. That also includes the ability to skip past to the next tower if you would rather hunt Citadels or Unique maps.

Waystones set the content for that map. THIS is where you determine that THIS map, based on the biome and specific map is a Ritual, or Expedition, or whatever.

Having Precursor Tablets apply to maps, AS WELL AS Waystones, and having Towers just be another map, that happens to reveal more of teh Atlas, but sometimes also influence the entire area is just odd.

TL;DR

Atlas Skill points are for GLOBAL changes that the player wants for ALL maps.

Precursor Tablets are ONLY for towers, to set the type of boosts you want for that area. Here you can experiment with strongboxes, Essences, etc

Waystones go in maps to set the specific content the player wants for that specific map.
