Solving the Issue of Charges and Totems

Generating and spending charges as it is is obviously something that a lot of players are annoyed with. Charges don’t have any inherent value, so give them some.

  • Assign a flat mana value for each charge. Power charges should be worth the most mana, then endurance, and finally frenzy charges being worth the least.
  • Add a tick box to some skills that expend charges in the skill panel, similar to minions.
  • Change the cost of using those skills to mana and make using charges optional.

For example, lets say an ancestral totem cost 525 mana to summon. For this example, assume an endurance charge is worth 150 mana. If you tick the box from 0 to +2, the cost to summon changes to 2 endurance charges and 225 mana. This can be further modified by mana cost efficiency, mana cost of skills, and mana cost converted to life.

This solution allows players to choose how they want to approach the cost of a skill in a dynamic way as well as opening up the amount of viable unique items and item modifiers worthwhile for builds that expend charges. Furthermore, it can make charge passive nodes a bit more interesting by, for example, increasing the mana value of a charge, decreasing the mana value and adding extra damage, gaining a free charge when you expend X amount of charges, things like that. It would open up some design possibilities with supports as well.

tldr; Assign flat mana values to charges. Allow players to choose how many they want to expend to cover the high mana cost of a skill.
