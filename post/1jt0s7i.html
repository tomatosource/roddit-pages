Path of Building Community PoE 2 v0.6.0 - Import from your characters + 0.2 Skills and Tree + more

Hey everyone, PoB can now finally import your build from the game with 1 click. No more manual copy-pasting every item! We’ll most likely have some issues with this, so let us know if something isn’t working

This update also includes support for the new 0.2 tree and gems. I added support for all the new active skill gems, but we still have a bunch of ascendancies, support gems and uniques to support. Those will be coming in smaller updates over the coming weeks.

Majochem added proper support for all the crossbow skills, so you can actually get a good idea of your DPS.
It properly takes into account your ammo capacity and reload speed to figure out your actual uptime firing shots, so it is a great addition.

Known Issues

  • Importing items that grant skills isn’t working properly
  • Converting your 0.1 tree to 0.2 changes your ascendancy / class
