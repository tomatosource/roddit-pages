Swapping weapons and using a skill doesn’t use previous weapons support gems

To clarify, if you use a combo or strong of skills, and weapon swap to a weapon to use a skill that wasn’t bound to the first few skills you used, the support gems of the first skills used will not work unless that weapon that used them is still equipped when the skill does damage.

For instance, on my Witch, I can use Despair on my weapon set two as I have curse stuff on Weapon set 2. I have the same weapon bound for both weapon sets. When I use despair, I have Burning Inscription on it. I cast it, then I swap back to weapon set one to start slinging chaos spells. When despair activates, burning inscription DOES NOT _unless_ I specifically have weapon set two out. I assume this interaction works with any weapon skill set up that has some form of delayed damage.

Don’t know if this is a bug or working as intended, but worth taking a look at.
