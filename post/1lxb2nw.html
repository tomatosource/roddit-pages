Support gem screen needs a rework

There needs to be a way to use support gems already cut and in the stash while using an uncut gem.

I don’t have all the possible gems that fits all possible skills memorized, so quite often I’d open up an uncut gem menu, then choose gems to put into a new build and skill. But since I have a stash full of cut gems I end up closing the uncut menu and have to search for the gem.

It’d be much better if the game asks you if you want to use a precut gem you already own or cut a new one.
