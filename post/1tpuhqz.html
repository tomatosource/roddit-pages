Path of Levelling 2 - A PoE 2 Overlay With Linux Support

Hey everyone! I’ve just released the latest update to Path of Levelling 2 - a levelling overlay which displays layout images and notes for (most) combat zones in the game, now with way more customisation! The app reads the Client.txt that PoE2 spits out during play and automatically updates the notes and images, which is the same way that all the levelling overlays in PoE1 worked.

You can get the latest release here and check out the Quick Start guide here!

Path of Levelling 2 features:

  • Customisable Act and Zone notes that automatically update as you change zones
  • Layout Image references that automatically update as you change zones (Thanks to Lolcohol for letting me use his images!)
  • Customisable Gem Setups that automatically update as you level
  • A Level Tracker that displays your level difference with the current zone + EXP multiplier

The app supports Windows 10+11 via installer or portable, and Linux on X11 (with experimental support for Wayland) via AppImage.

You can click through all the components so you’ll never accidentally click the overlay instead of PoE, then you can hit Ctrl+Alt+S to open the settings and fully drag/resize all the components. Note that all the components start in the top left so they don’t get lost offscreen on low resolutions.

Hope everyone has a great league start, huge thank you to everyone who has tried my app so far, and good luck in 0.5!
