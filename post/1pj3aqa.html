[OC] [Tech] I built a “Spoiler-Free” NBA Excitement Rater for non-US fans. Seeking feedback on the volatility algorithm logic.

Hey all,

I’m a European fan who was tired of spoiling games while checking box scores in the morning, so I built a small site that ranks games by “excitement” without showing scores or winners.

Site: https://replayrank.com

Each game gets an Excitement Score (0–100) and a label like “MUST WATCH” or “Background Noise”.

How the score works (no spoilers)

It’s a pure rules-based algorithm using play-by-play + box score data:

• Closeness & margin

Smaller final margin = higher score; blowouts get penalized. Very close games (≤5 pts) get a “Down to the Wire” bonus.

• Volatility

Lead changes + times tied add to the score. Crazy swings can get tagged as “Back & Forth Battle”.

• Overtime

Each OT adds a big bonus (multi-OT games tend to land near the top).

• Star performances

Big scoring nights and triple-double-type lines boost the rating and can trigger tags like “Star Takeover” or “Historic Performance”, without showing the actual stat line on the site.

• Final-minute drama

The algorithm scans the last minute of the 4th/OT for lead changes and shots that could win or tie the game (including dramatic misses), adding extra clutch bonuses.

• Game style

High-scoring shootouts get a small bump; low-scoring blowout snoozers can get tagged as “Defensive Struggle”.

All components are combined and then capped so one thing (like a single stat line) doesn’t completely dominate.

What I’m looking for

If you try it, I’d love feedback on:

• Do the top games feel right?

• Any games you’d rate very differently?

• Any tags that feel misleading/confusing?

Examples like “[Team A] vs [Team B] on [date] was amazing but your score is too low” are super helpful. Thanks!
